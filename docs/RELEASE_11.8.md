# Deep Vision Studio Desktop 11.8

PatchCore 추론 점수를 0~1로 표시하고 임계값으로 OK/NG를 조절합니다.

- 점수 < 임계값: OK (정상 학습 데이터와 유사), 점수 >= 임계값: NG (정상 학습 데이터에서 멂).
- 고정 변환 `score = raw_distance / (raw_distance + scale)`. 양수인 저장 임계값을 scale로 사용하여 기존 경계가 0.5가 됩니다. 이미지별 또는 배치별 최솟값/최댓값은 사용하지 않습니다.
- 새 모델에는 변환 기준을 저장합니다. 기존 모델은 저장 임계값에서 같은 기준을 복원하므로 재학습이 필요하지 않습니다. 기존 PatchCore 작업 결과도 검수 화면에서 같은 방식으로 변환합니다.
- 임계값이 없는 모델은 scale=1로 표시하며 미보정 상태를 유지합니다. 사용자가 임계값을 지정해야 OK/NG로 분류합니다. 0 이하인 기존 임계값은 0으로 대응합니다.
- 표, 이미지 판정, 필터와 슬라이더가 같은 점수를 사용합니다. PatchCore 임계값 입력과 슬라이더 범위는 항상 0~1입니다.
- 원래 거리값, 원래 임계값, 정규화 기준은 결과 details에 보존합니다. 기존 체크포인트의 raw predict API와 학습 평가 점수 단위는 유지합니다.
- 0~1 점수는 모델 기준의 이상 거리이며 불량 확률 또는 정확도 백분율이 아닙니다. 히트맵의 이미지별 색상 범위와 판정 점수 정규화는 별개입니다.

검증 범위: 점수 순서와 경계, 배치 독립성, 구형 체크포인트 및 저장 작업 호환, CPU 모델 저장/재로드/독립 프로세스 추론, Qt 임계값과 필터. 실제 검사 데이터의 미검률/과검률 개선을 주장하는 변경은 아닙니다.

데스크톱 릴리스에는 소스 ZIP만 첨부하며 EXE를 첨부하지 않습니다.
