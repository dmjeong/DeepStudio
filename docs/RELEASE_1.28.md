# 1.28 — 기본 모델 관리와 학습 카드 회귀 수정

왼쪽 메뉴에 **Settings**를 추가했다. 카탈로그의 모델은 모두 설치본 기본 모델로 표시하며,
사용자가 추가한 Docker `.dvmodel`만 별도 항목으로 분리해 안전하게 설치·새로 고칠 수 있다.

학습 화면은 모델 선택과 학습에 집중한다. Settings에서 설치한 추가 모델 팩은 현재 프로젝트의
모델 카탈로그에 즉시 반영된다. 기본 모델에 Docker 팩 설치를 요구하지 않는다. 설치된 팩
코드나 가중치를 Settings 화면에서 직접 실행하지 않으며, 체크섬·서명 검증을 통과한 팩만 활성화한다.

Qt 위젯을 축소해 학습 차트만 확인하는 회귀 검사에서 에폭 시간 카드 호출이 예외를 내던 문제도
수정했다. 실제 화면에서는 최근 에폭 시간과 누적 시간을 계속 표시한다.

사용자 버전 규칙에 따라 Settings 화면 기능은 1.17에서 **+0.1**으로 1.27이 되고, 이번 버그
수정은 **+0.01**이므로 최종 버전은 1.28이다.
