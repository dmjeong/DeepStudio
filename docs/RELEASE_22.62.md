# 22.62 main 병합 후 버그 수정

**분할 학습의 정답 확인.** 마스크가 없는 이미지는 계속 배경(0번)으로 학습합니다. 다만 학습 폴더 전체에 마스크가 하나도 없으면 "정답 마스크가 하나도 없습니다"로 멈춥니다. 검증 폴더는 정상 이미지만 있어도 됩니다.

**탐지 신뢰도 기준.** 신뢰도가 기준과 정확히 같은 박스의 처리를 학습 앱과 맞췄습니다.

| 모델 | 남기는 박스 |
|---|---|
| Custom CSP | 점수 ≥ 기준 (앱과 같음, 22.61 SDK는 버림) |
| LibreYOLO YOLO9, D-FINE, RE-DETR | 점수 > 기준 (변경 없음) |

Custom CSP 탐지 모델을 C++·C#으로 배포한다면 이 버전의 SDK로 다시 빌드하세요. 모델을 다시 내보낼 필요는 없습니다.

**프로젝트 저장.** 다른 이름으로 저장할 위치에 깨진 JSON이나 프로젝트가 아닌 JSON이 있으면 덮어써 저장합니다. 내용이 같은 프로젝트를 다시 저장하면 수정 시각을 유지합니다.

**기타.**
- Custom CSP 원본 크기 학습의 실행 폴더 이름에 채운 입력 크기 대신 `original`을 씁니다.
- 저장된 프로젝트 파일을 작업 계산 프로세스에 그대로 넘겨도 학습 기록이 프로젝트 폴더에 생깁니다.
