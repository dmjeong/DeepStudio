# 추론 입력 영역

추론 화면의 입력 영역에서 다음 중 하나를 선택합니다. 모든 태스크와 CPU/GPU 추론에 같은 선택 규칙을 적용합니다.

| 선택 | 입력 처리 |
| --- | --- |
| 모델 설정 사용 | 체크포인트에 저장된 중앙 크롭을 적용합니다. 저장된 크롭이 없으면 원본 전체를 사용합니다. |
| JSON 설정 사용 | 선택한 JSON의 중앙 크롭을 적용합니다. 파일에서 읽은 크기를 화면에 표시합니다. |
| 원본 전체 사용 | 저장된 중앙 크롭을 이번 추론에서 해제합니다. |

중앙 크롭은 원본 픽셀 기준입니다. 이후 크기 조정, 정규화 등 해당 모델의 기존 전처리를 적용합니다. 최종 입력 크기는 모델 설정을 따릅니다. JSON은 입력 영역만 지정하며 가중치, 채널 수, 최종 모델 입력 크기를 변경하지 않습니다. 공식 분류 모델의 기본 전처리에 포함된 Resize/CenterCrop도 유지됩니다.

직접 작성하는 JSON 예시:

```json
{
  "center_crop": {"width": 1024, "height": 768}
}
```

정사각형 NxN 크롭은 width와 height를 같은 값으로 지정합니다. `{"center_crop": null}`은 원본 전체입니다. 가로와 세로는 1~65536의 정수여야 하며, 원본보다 큰 크롭은 해당 이미지의 오류로 기록합니다. 자동 확대나 패딩으로 대체하지 않습니다.

Studio ONNX 내보내기 JSON의 `preprocessing.center_crop`, 학습 스냅샷의 `center_crop.json`, 저장된 `.dvproj`의 `training.patchcore_crop_enabled/width/height`도 읽습니다. 크롭이 없던 구형 ONNX JSON(schema_version 1)은 원본 전체로 해석합니다. 불명확하거나 서로 충돌하는 설정은 실행 전에 오류를 표시합니다.

작업을 시작할 때 JSON 내용을 고정합니다. 작업 도중 파일 수정이나 삭제가 있어도 배치의 입력 영역은 바뀌지 않습니다. 결과와 input_manifest.json에 선택 방식, 실제 크롭, 모델에 저장된 크롭, 모델 입력 크기, JSON 경로와 SHA-256을 기록합니다. 이전 결과는 당시 설정을 유지하며 선택 변경 후 다시 추론해야 새 결과가 생깁니다.

검출 박스, 분할 마스크와 히트맵은 선택한 영역을 기준으로 계산하고 원본 좌표에 복원합니다. 영역 밖 히트맵을 검사 결과로 표시하지 않습니다. 모델 파일이나 PatchCore 메모리 뱅크의 저장 설정은 수정하지 않습니다. 모델 설정 사용으로 돌아가면 저장된 크롭이 다시 적용됩니다.

학습과 다른 영역을 선택하면 점수 분포와 정확도가 달라질 수 있습니다. 이상 탐지의 저장된 임계값은 유지하므로, 운영에 사용할 영역으로 실제 이미지의 판정을 확인해 주세요.
