# 22.92 — 파일명 버전으로 여러 분류 모델 교체하기 (+0.1)

[CSeVision 적용 코드·샘플 CSV·사용 방법](../example/cpp/with_evision/FILENAME_CSV_MODELS.md)

## 변경

- CSV는 `index,camtype,task,name` 네 열이다. 별도 버전 열 없이 파일명
  `sevision_ai_261126_16H.dvsenc`의 날짜·시간을 사용한다. 분·초 형식도 지원한다.
- 하나의 감시 스레드가 모든 행을 확인하고 더 최신인 모델만 복호화·초기화·워밍업한다.
- 추론은 원자적으로 받은 shared_ptr로 실행하며 기존 모델의 Context를 재사용하지 않는다.
- 모델은 준비되는 대로 index별로 교체된다. 미완성/잘못된 모델은 기존 모델을 유지하고 재시도한다.
- 같은 이름/이전 버전은 재로드하지 않는다. 기존 index의 카메라·태스크·파일명 앞부분 변경이나
  행 삭제는 실행 중 거부한다. 새 index 추가는 지원한다.
- 기존 고정 파일명 + `model_version` CSV 관리기와 분류기 계산 코드는 유지한다.

## 검증

공개 합성 암호화 모델로 날짜·CSV 파싱, 다중 카메라 라우팅, 동시 추론 중 교체,
이전 모델 유지/회수, 파일 누락 재시도, 변조·키·입출력 오류, 이전 버전 거부,
CSV 순서/수정 시각 불변 변경, 초기화 실패/초기 로드 중 변경을 검증한다.
Windows 설치본에 새 예제와 CSV/공개 모델이 포함되는지도 검사한다.

로컬 검증 결과: C++17·ONNX Runtime 1.22.0 네이티브 검사 9개 통과,
버전 정책·Windows 설치본 포함 검사 35개 통과. 새 예제와 회귀 코드는
Clang `-Wall -Wextra -Werror` 검사도 통과했다.

BW8 분류 전용이다. 분할·탐지 로더와 같은 인터페이스라고 주장하지 않는다.
로컬 C++17/macOS·ONNX Runtime 검증과 실제 VS2017/eVision SDK 검증은 구분한다.
실제 검사 모델로 교체하는 동안의 지연시간과 메모리는 대상 PC에서 측정해야 한다.
