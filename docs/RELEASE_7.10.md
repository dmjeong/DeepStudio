# Deep Vision Studio React 7.10

7.9 로컬 웹 버전의 프로젝트 복구와 학습 결과 표시 오류를 수정한 릴리스다.

- 열린 프로젝트 파일이 이동, 삭제 또는 손상되어도 상태 API가 오류 안내와 최근 경로를 반환한다. 프로젝트 화면에서 다른 파일을 열 수 있고, 이전 메모리 상태로 사라진 파일을 다시 저장하지 않는다.
- 작업 종료 후 프로젝트 새로고침에 실패해도 실제 계산 결과와 성공, 실패, 중단 상태를 보존한다. 프로젝트 복구 오류는 별도로 표시한다.
- 학습 중 과거 Run을 선택하면 해당 Run의 그래프와 Best 손실을 표시한다. 현재 학습은 별도 선택 항목이며 새로고침 시 진행 중인 학습을 선택한다. 이어학습 Best 손실은 실제 에폭 번호로 조회한다.
- 동시 프로젝트 조회와 열기가 충돌하지 않도록 프로젝트 새로고침에도 작업 잠금을 적용했다.

프로젝트 이동 및 손상 복구 API 검사, 작업 결과 보존 검사, 학습 결과 선택 검사 4개를 추가했다. 릴리스는 Windows/Linux Python 회귀 검사, Python lint, React 검사와 빌드, FastAPI 정적 파일 검사, C++ 계약 검사를 통과한 커밋에서 생성한다. 실제 브라우저 조작과 사용자 데이터셋의 GPU 학습은 이 자동 검사 범위에 포함되지 않는다.

실행용 `Deep-Vision-Studio-React-v7.10.zip`을 새 폴더에 풀고 `DeepVisionStudio/start_web.bat` 또는 `python run_web.py`로 실행한다. 7.9의 Python 의존성을 설치한 환경을 그대로 사용할 수 있다. 자세한 최초 설치 절차는 `docs/LOCAL_WEB.md`를 참고한다.
