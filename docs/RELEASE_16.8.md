# React 16.8: 추론 입력 영역 선택과 화면 개선

- 추론 화면에서 모델 설정 사용, JSON 설정 사용, 원본 전체 사용을 선택합니다.
- JSON에서 읽은 중앙 크기를 표시하며 프로젝트별 선택과 파일 경로를 복원합니다.
- 분류, 검출, 세그멘테이션, PatchCore, 재구성 이상 탐지에 적용합니다.
- JSON은 작업 시작 시 고정하고 사용한 영역과 JSON SHA-256을 결과에 기록합니다.
- 모델 파일의 학습 설정을 보존하며 박스, 마스크와 히트맵을 실제 입력 영역에 맞춰 복원합니다.
- 모델 로드 영역과 우측 배치 결과 표의 간결한 배치를 유지합니다.
- 데이터셋 격자는 양방향 스크롤을 제공하고, 썸네일을 열면 원본 이미지 확대 화면을 사용합니다.
- 격자 썸네일에는 확대 조작을 두지 않으며, 선택 이미지 상세 화면에서만 확대합니다.
- 추론 상세 영역은 태스크에 따라 분류 전체 확률, 검출 목록, 세그멘테이션 픽셀 분포, 이상 점수와 판정을 표시합니다.

사용법과 JSON 예시는 [추론 입력 영역](INFERENCE_REGION.md)을 참고해 주세요.

검증 범위: JSON 호환성과 오류 처리, 실제 Custom 네 태스크와 공식 분류 CPU 입력 비교, 16비트 PatchCore 입력과 히트맵, Qt 별도 프로세스 전환, 웹 배치 JSON 고정, 배포 ZIP 브라우저 설정과 레이아웃. Windows/Linux CI 통과 후 태그와 패키지를 게시합니다. 현장 데이터 정확도와 GPU 성능은 별도 검증 대상입니다.
