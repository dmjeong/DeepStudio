# 16.89 — 새로운 결함 형상과 독립 이미지 저장

기존 참조 형상 이식에 새 형상 생성 기능을 추가했다. 신규 기능 +1.0 정책에 따라 15.89에서 16.89로 올렸다.

- **crack**: 실제 참조의 명암·색을 사용하되 균열 경로, 굽음, 가지, 두께를 새로 만든다. 최소 1px 두께로 생성한다.
- **foreign material**: 참조의 색·질감을 바탕으로 불규칙한 새 윤곽을 만든다.
- **shift/double/flip**: 라벨링된 물체 배치를 하나의 단위로 크기·각도 변형한다. 정상 트레이 격자·이웃 칩까지 함께 회전시키지 않는다.
- **크기 35~300%, 강도 20~300%, 형상 변화 0~100%**를 설정할 수 있다. 기본 크기 65~145%, 강도 60~150%. 같은 시드·설정은 같은 실행 환경에서 재현된다.
- **이미지·정답 PNG 저장**: 선택 후보 / 승인 전체 / 제외하지 않은 전체 중 선택한다. 미리보기의 색칠 표시 없이 원본 해상도 사진과 클래스 번호 마스크를 새 폴더에 저장한다. 같은 후보를 다시 저장해도 기존 파일을 덮어쓰지 않는다. 마스크 편집 내용과 Train/Val 출처를 보존한다.

사용 위치: **Data Gen → SEG 정답으로 가상 불량 → 프로젝트 정답 분석 → 새 형상 생성 → 미리 생성/설정 수량 생성 → 이미지·정답 PNG 저장**.

저장 폴더의 `images/train`(또는 `val`)과 `masks/train`에 동일 이름의 PNG가 들어간다. `manifest.json`에 클래스·시드·변형·검수 상태를 기록한다. 기존의 **승인본 포함 새 학습 프로젝트 저장**도 사용할 수 있다.

47개 합성 관련 검사로 RGB/흑백, 크기·명암 변화, 재현성, 배경 보존, 원본 보호, 마스크 수정 후 저장, 취소 시 정리, 실제 GUI/작업 프로세스, 학습/ONNX 연동을 확인했다. 3504×1504 자체 제작 트레이에서도 5개 결함 종류를 생성했다. [사용법과 결과](SEGMENTATION_SYNTHESIS.md).

이 기능은 명시적인 형상 알고리즘을 사용하는 생성·합성이다. 실제 새로운 불량의 물리적 발생 과정을 학습한 확산 모델은 아니다. 학습용 보조 데이터로 사용하고 실제 Val/Test에서 검출 성능을 확인한다. 새 모듈은 Windows EXE 패키징 목록에도 포함했다.
