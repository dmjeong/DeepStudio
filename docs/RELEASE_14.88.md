# 14.88 — SEG 합성 중복 입력 허용 (+0.01)

중복 이미지가 있어도 SEG 가상 불량 분석과 생성을 진행한다.

- 같은 폴더와 Train/Val/Test 사이의 동일 픽셀 이미지를 모두 허용한다.
- 파일마다 자기 분할과 정답을 유지한다. 중복 이미지에 서로 다른 정답이 있어도 하나를 버리거나 합치지 않는다.
- 승인본 포함 새 학습 프로젝트에도 중복 원본과 각 정답을 모두 복사한다.
- 분석 상세에 중복 입력 수를 표시하며, 별도 체크나 확인 창은 없다.
- Train 참조는 Train 바탕, Val 참조는 Val 바탕에 사용한다. Test는 참조로 쓰지 않는다.

**업데이트 후 ‘프로젝트 정답 분석’을 다시 누르면 된다.** 기존 모델 재학습은 필요 없다.
