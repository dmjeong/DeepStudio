# Deep Vision Studio React 14.8

PatchCore 학습 화면에 중앙 크롭 설정을 추가합니다.

- 중앙 크롭 사용 여부와 가로, 세로 크기를 원본 픽셀 단위로 설정합니다. 정사각형과 직사각형을 지원합니다.
- 원본 중앙 크롭 후 모델 입력 크기로 리사이즈합니다. 예: 2048×2048 → 중앙 1024×768 → 모델 입력 224×224.
- 학습, 검증, 추론에 같은 크롭을 사용하며 프로젝트와 모델에 설정을 저장합니다.
- 크롭을 사용한 모델을 로드하면 추론에 자동 적용됩니다. 판정과 히트맵은 크롭 영역만 대상으로 합니다.
- 원본보다 큰 크롭은 파일명과 함께 오류를 표시합니다. 추가 학습 시 기존 메모리 뱅크와 크롭 설정이 다르면 새 뱅크 구축이 필요합니다.
- RGB, 회색조, 16비트 높이 이미지에 적용하며 EXIF 방향 처리와 원본 좌표 히트맵을 검증합니다.

크롭한 영역 안에 불량이 있는 이미지로 평가해야 합니다. 기존 전체 이미지 모델을 중앙 크롭 검사로 바꾸려면 크롭 설정으로 메모리 뱅크를 다시 구축해야 합니다. 크롭 모델은 이번 버전 이상의 Studio에서 사용합니다. 기존 크롭 없는 모델은 전체 이미지로 추론합니다.

적용 범위는 PatchCore입니다. 정렬되지 않은 대상의 위치를 찾는 기능과 이미지 전체를 여러 조각으로 나누는 타일링은 포함하지 않습니다.

검증: 중앙 좌표와 홀수 크기, 16비트 픽셀, EXIF 회전, 모델 저장/로드와 CPU 추론, 기존 뱅크 추가 학습 조건, Qt 설정 복원, React 배포 ZIP의 설정 저장/재로드 및 범위 검사.
