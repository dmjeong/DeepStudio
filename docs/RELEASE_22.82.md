# 22.82 — CSV 감시 기반 C++ 모델 교체 예제

[전체 사용법과 코드](../example/cpp/with_evision/CSV_MODEL_RELOAD.md)

## 설계

- 사용 대상: C++17·ONNX Runtime·암호화 분류 모델·BW8/EROIBW8 입력.
- 작은 CSV 내용을 주기적으로 읽고 새 버전만 적재한다. 고정 모델 파일명을 지원한다.
- CSV와 암호화 파일 내부 버전이 같고, 새 모델 초기화와 준비 추론이 성공해야 교체한다.
- 현재 진행 중인 추론은 자신이 받은 `shared_ptr` 모델로 끝낸다.
- 이전 모델은 사용자 참조가 사라질 때 감시 스레드에서 해제한다. 사용 중인 과거 모델이 있으면
  다음 교체를 기다려 세션 수가 계속 늘어나는 것을 막는다.

## 구현

`example/cpp/with_evision/csv_model_watcher.h`와 인자 없는 `csv_reload.cpp`를 추가한다.
기존 분류기와 ONNX 계산·전처리 코드 변경 없이 연결한다.
클래스의 입출력 규격·정규화·실행 설정은 모델 내부 정보를 따른다.
분할·탐지를 이 분류 로더로 실행할 수 있다고 표시하지 않는다.

## 검증 결과와 한계

네이티브 회귀 검사에서 CSV 따옴표·UTF-8·BOM·날짜 검증, 중복 행 거부,
고정 파일명 교체, 수정 시각 불변 변경 감지, 4개 스레드 동시 추론,
변조·잘못된 입출력·버전 불일치 거부, 같은 CSV의 재시도,
로드 중 CSV 변경, 사용 중인 이전 모델 유지·회수를 확인한다.

macOS C++17·ONNX Runtime 1.22.0에서 네이티브 예제·회귀 검사 7개를 통과했다.
새 헤더는 경고를 오류로 처리하는 Clang 빌드도 통과했다.
버전 정책·Windows 설치본 예제 포함 검사 35개도 통과했다.

테스트 모델은 저장소의 공개 합성 그래프다. 실제 검사 모델의 교체 지연시간이나
메모리 사용량은 사용자 PC에서 별도로 측정해야 한다.
Windows VS2017/v141과 실제 eVision SDK 실행을 로컬 macOS 테스트로 대신 보증하지 않는다.
