# 21.59 CPU 정밀도 비교에서 응답이 멈출 때

**내보내기 → CPU 실행기·정밀도 비교**에 **단계별 제한 시간**을 추가했습니다. 기본값은 60초입니다. 이 시간 동안 모델 로딩, 워밍업 한 회, 이미지 한 장의 측정 등에서 다음 단계로 진행하지 못하면 해당 작업 프로세스를 종료합니다.

표에 **시간 초과**로 표시하고 이미 측정한 결과를 유지합니다. 다른 실행기, 정밀도, 스레드 수의 조합은 계속 진행합니다. 로그와 결과 행에 마지막 단계와 측정 중인 파일명이 표시됩니다. **중단**을 누르면 현재 작업을 종료하고 완료된 행을 남깁니다.

CPU에서 큰 입력을 측정하는 경우 단계별 제한 시간을 조절할 수 있습니다. 측정 시간은 선택한 런타임과 정밀도에서 실제로 완료된 실행을 기준으로 집계합니다.
