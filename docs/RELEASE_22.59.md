# 22.59 분류 모델과 지식 증류

| 데스크톱 Classification 모델 | 기본 입력 | 백본 가중치 | 용도 |
|---|---|---|---|
| DINOv2 ViT-L/14 | 224×224 | 약 1.22GB · Apache-2.0 | 자기지도 학습 특징으로 전이학습 및 교사 학습 |
| SigLIP 2 So400m/16 | 384×384 | 약 1.71GB · Apache-2.0 | 대형 이미지 인코더로 전이학습 및 교사 학습 |

두 모델은 흑백·컬러 입력을 지원하며 프로젝트 클래스에 맞는 분류 헤드를 학습합니다. 추가 다운로드는 약 2.9GB입니다. 체크포인트와 ONNX 변환 임시 파일용 공간도 필요합니다. 전체 백본을 학습하면 AdamW 상태와 역전파용 메모리가 추가됩니다. GPU 학습을 시작할 때는 배치 1~2, AMP, 백본 레이어 동결로 분류 헤드부터 평가할 수 있습니다.

Python 실행 환경에서 새 가중치만 준비하려면 저장소 루트의 명령 프롬프트에서 실행합니다.

```bat
python python\prepare_builtin_assets.py --only dinov2_vitl14,siglip2_so400m_cls
```

빌드할 때는 `gui\build.bat`가 기본 가중치를 준비합니다. 수동 설치 시 **설정 → 사전학습 가중치**에서 공식 파일을 가져올 수 있습니다. 재배포 시 라이선스와 제3자 고지를 함께 제공합니다. [제3자 고지](../THIRD_PARTY_NOTICES.md)

## 교사와 학생 학습

1. **학습 → Classification**에서 DINOv2 ViT-L/14 또는 SigLIP 2를 선택합니다. 사전학습 가중치로 시작해 검사 클래스 기준으로 학습하고, 저장된 Best 체크포인트를 준비합니다.
2. 같은 클래스 이름을 가진 프로젝트에서 학생 모델로 EfficientNet B0/B1 또는 ResNet·ConvNeXt·DINOv2·SigLIP 2를 선택합니다. **교사 증류 (선택)** 에 교사의 `.pt`를 지정합니다. 흑백·컬러 설정은 교사와 학생이 같아야 합니다. 클래스 순서와 입력 크기는 달라도 됩니다.
3. 증류 비중 **0.30**, 온도 **2.0**으로 시작합니다. 학습에서는 같은 증강 이미지를 교사 입력 높이·너비에 맞춰 리사이즈하고, 교사 점수와 정답을 함께 사용합니다. 검증, Best 선택 및 종합 평가는 학생의 결과를 정답과 비교합니다.
4. 학생 Best 체크포인트를 **내보내기 → ONNX**에서 선택합니다. C++에서는 학생의 ONNX와 JSON을 기존 분류 예제로 읽으면 됩니다. 교사는 학습할 때만 필요합니다.

INT8은 **출력 검증**과 **보정 이미지 폴더**가 필요합니다. 결과 JSON의 `top1_agreement`에서 FP32와 판정이 얼마나 일치하는지, `changed_images`에서 판정이 달라진 보정 영상을 확인할 수 있습니다. 현장 모델을 선택할 때는 별도 시험 세트에서 클래스별 미검률과 추론 시간을 비교하세요.
