# 13.84 — 세그멘테이션 비교 모델 5종

신규 모델 추가 릴리스(+1.0). 기존 모델의 체크포인트는 그대로 사용할 수 있습니다.

## 사용

Python 실행 환경은 소스를 업데이트한 뒤 `gui\update_segmentation_models.bat`을 한 번 실행하고
앱을 다시 실행합니다. 기존 PyTorch/CUDA 설치를 교체하지 않고 timm과 새 백본 가중치를 준비합니다.
EXE 배포는 `build.bat`으로 다시 빌드하면 필요한 코드·패키지·가중치가 포함됩니다.

Training → Segmentation에서 다음 모델을 선택합니다. Docker나 .dvmodel은 필요하지 않습니다.

| 화면 모델 | 기본 사전학습 | 학습 시작 방법 |
| --- | --- | --- |
| U-Net / MobileNetV4 Conv-S | timm ImageNet 백본 | 사전학습 / 로컬 가중치 / 처음부터 |
| U-Net / ShuffleNetV2 x1.0 | torchvision ImageNet 백본 | 사전학습 / 로컬 가중치 / 처음부터 |
| U-Net / EfficientNet-B1 | timm RA4 ImageNet 백본 | 사전학습 / 로컬 가중치 / 처음부터 |
| BiSeNetV2 / Standard | 제공하지 않음 | 처음부터 / 같은 모델의 Studio .pt 추가 학습 |
| STDC / STDC1 | 제공하지 않음 | 처음부터 / 같은 모델의 Studio .pt 추가 학습 |

BiSeNetV2/STDC의 외부 공개 가중치는 코드 라이선스만으로 사용 조건을 확정하지 않았습니다.
기본 모델 구조와 학습 기능은 제공하며, 확인되지 않은 외부 파일을 자동으로 받지 않습니다.
모든 모델에서 배경은 마스크 0, 학습 제외는 255입니다. 1/3채널과 패치 학습을 지원합니다.

## 비교 설정

기존 모델과 같은 데이터 분할, 원본 배율, 패치 크기(예: 640), 증강, 학습률로 비교하세요.
U-Net 3종은 백본만 사전학습되어 있고 분할 헤드는 새로 학습합니다.
BiSeNetV2 보조 분할 손실(각 0.4), STDC1 보조 분할 손실(각 0.4)과 경계 BCE+Dice(1.0)는
학습에만 적용됩니다. 이 값은 training_config와 CSV에 기록됩니다.
검증 점수·best 선택·내보내기에는 주 출력만 사용합니다.

B1·BiSeNetV2·STDC1은 전역 문맥을 사용합니다. 패치 학습과 큰 판정 ROI의 통계가 다를 수 있으므로
실제 검사 ROI로 최종 평가하세요. INT8 보정은 품질 인증이 아닙니다. FP32 대비 오검출/미검출을 확인하세요.

## 배포

기존 ONNX 내보내기와 암호화 내보내기를 그대로 사용합니다. C++/C# 공통 SDK의 Segment 계약을
사용하며 모델마다 추론 코드를 바꿀 필요가 없습니다. ShuffleNetV2의 채널 재배열은 보정 패치 크기를
바꿔도 동작하도록 내부 Shape 연산을 유지하면서 외부 입출력 크기는 기존 SDK와 같이 고정합니다.

## 검증 범위

새 5종의 RGB/흑백·홀수 크기·배치 1 역전파, 학습/검증·best 저장/재로드·클래스 변경 추가 학습,
Qt 모델/학습 모드 선택, FP32 ONNX 출력 비교, INT8 변환/실행을 검사했습니다.
C++ Release의 분할 마스크와 ONNX Runtime 결과, 평문/암호화 출력 일치도 검사했습니다.
세 U-Net은 실제 공식 가중치 다운로드/해시/로드 후 합성 데이터 1에폭 학습과 ONNX 내보내기도 확인했습니다.

개인 검사 데이터의 정확도, Windows 설치본 실행, CUDA 학습은 이 macOS 로컬 검사로 검증되지 않습니다.

실행 결과와 검토 사항: [검증 보고서](03-analysis/segmentation-model-candidates.md).
