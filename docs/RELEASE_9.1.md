# Deep Vision Studio React 9.1

GPU 학습이 CPU 설치와 조용한 장치 전환으로 느려지는 회귀를 수정합니다.

- NVIDIA GPU가 있는 웹 신규 설치와 기존 CPU 전용 환경은 CUDA 패키지로 자동 복구합니다. 정상 CUDA 환경은 유지합니다.
- 데스크톱 배포 EXE는 CUDA 13.0 런타임을 포함합니다. NVIDIA 드라이버 580 이상이 필요합니다.
- GPU를 요청했는데 CUDA를 사용할 수 없거나 GPU 번호가 잘못됐으면 명확한 오류를 표시합니다.
- 실제 학습 프로세스에서 선택한 GPU의 합성곱과 역전파를 검사하고 GPU 이름과 CUDA 버전을 로그와 실행 기록에 저장합니다.
- CPU 장치 선택은 계속 지원합니다.

검증 범위: 장치 선택과 자동 설치 회귀 검사, Windows 패키지 런타임 검사. GitHub 기본 실행기에는 GPU가 없어 실제 CUDA 학습의 완료 여부는 해당 환경에서 검사하지 않습니다. GPU PC에서는 학습 시작 시 실제 CUDA 연산 검사가 자동 실행됩니다.
