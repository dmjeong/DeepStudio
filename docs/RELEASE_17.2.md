# Desktop 17.2: 프로젝트 화면 겹침 수정

- 태스크 카드에 기존 어두운 배경과 태스크별 강조 색상을 복원합니다.
- 고정 카드 높이를 제거하고 줄바꿈된 제목과 설명에 맞춰 높이를 확보합니다.
- 창 너비에 따라 태스크 카드를 3열, 2열, 1열로 배치하고 카드 간격을 12px로 유지합니다.
- 프로젝트 페이지에 세로 스크롤을 적용해 설정, 생성 버튼, 최근 프로젝트가 겹치지 않게 합니다.
- Windows와 Linux에서 100%, 125%, 150% 배율의 실제 Qt 화면을 검증합니다.

첨부 파일은 소스 ZIP입니다.
