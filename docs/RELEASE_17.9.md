# React 17.9: OBB 프로젝트와 편집 안정화

- 분류, 탐지, 세그멘테이션, OBB 프로젝트에는 초기 클래스가 한 개 이상 필요합니다.
- Anomaly 프로젝트의 클래스는 자동 생성되며 클래스 입력을 비활성화합니다.
- OBB 연속 클릭의 좌표 누락과 저장 버튼 연속 입력의 중복 작업을 차단합니다.
- 여러 회전 박스 생성, 삭제, 클래스 변경과 저장 후 재확인을 검사합니다.
- 태블릿 크기에서 확대된 이미지의 가로와 세로 스크롤 및 화면 넘침을 검사합니다.
- 저장 실패 시 편집기와 정답을 유지하고 같은 화면에서 다시 저장할 수 있습니다.

라벨 저장은 기존과 같이 작업이 완료된 뒤에만 편집기를 닫습니다. 이번 릴리스는 OBB 화면과 프로젝트 생성 경로의 버그 수정 릴리스입니다.
