# Deep Vision Studio Desktop 11.70

PatchCore 학습의 데이터 증강을 실제 특징 수집에 연결했습니다. 기존에는 UI가 비활성화되어 있었고 로더에도 증강 경로가 없었습니다.

## 사용 방법

1. PatchCore 학습에서 **고급 설정: 최적화 상세와 데이터 증강**을 엽니다.
2. **원본당 추가 증강 수**를 설정합니다. 0이면 끔, 2이면 원본 1장과 증강 2장을 처리합니다.
3. 좌우 반전 확률·회전 각도·색상 변화 범위를 설정합니다. 뒤집힘이나 회전이 검출할 불량에 해당하면 해당 증강은 0으로 두세요. 증강 영상도 정상 특징으로 저장됩니다.

원본은 항상 포함하고 검증·추론에는 증강하지 않습니다. 특징 선택 시드와 같은 원본/추가 증강 번호에서는 같은 변형을 생성합니다. 회전 테두리는 검은색을 넣지 않고 반사 방식으로 채웁니다. 기존 프로젝트는 추가 증강 수 0으로 이전 동작을 유지합니다.

## 코어셋 비율과 소요시간

최종 신규 대표 특징 수는 **비율로 계산한 요청 수, 후보 수, 메모리 잔여 수 중 가장 작은 값**입니다. 비율이 커도 한도에 걸리면 더 저장되지 않습니다. 비율은 대표 특징 선별 단계에 영향을 주며 원본 특징 추출량을 늘리는 설정은 아닙니다. 증강 수/입력 크기/원본 수를 늘리면 추출량이 증가합니다.

로그에 요청/실제 개수, 제한 사유, 특징 추출 시간, 코어셋 선별 시간을 표시합니다. 이 내역과 적용 증강은 체크포인트 및 CSV 하이퍼파라미터에도 저장합니다. 후보 전체를 저장하는 경우 선별을 생략하므로 시간은 비율에 단순 비례하지 않습니다.

현재 ONNX 배포는 대표 특징 4096개 이하를 지원합니다. 증강 또는 대표 특징 수를 늘리는 것이 검출 성능을 자동으로 높인다는 뜻은 아니며, 독립 시험 데이터로 확인해야 합니다. 새 증강/비율을 반영하려면 정상 특징 뱅크를 다시 구축하고 판정 기준도 다시 보정해야 합니다.
