# Desktop 18.2

- Detection 데이터셋에서 이미지 더블클릭, 편집 버튼, 우클릭 메뉴로 객체 라벨 편집기를 엽니다.
- 클래스 선택 후 대각선 두 모서리를 클릭해 박스를 생성합니다. 객체마다 클래스 변경과 삭제가 가능합니다.
- 편집기 안에서 사용자 클래스를 프로젝트에 추가하고 이전 모델 정답을 저장합니다.
- 새로 추가한 이미지가 클래스 필터에 가려지지 않도록 전체 보기로 전환합니다.
- 데이터 추가 도구를 여러 줄로 나누고 기존 다크 테마를 유지합니다.
- Windows와 Linux 회귀 검증 후 소스 ZIP만 배포합니다.
