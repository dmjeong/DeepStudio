# 1.07 — 분할 마스크 티칭과 Best 선정 기준

신규 분할 편집기 추가로 사용자 버전 규칙의 **+1.0**을 적용한다(0.07 → 1.07).

Qt와 브라우저 데이터셋 화면에서 다각형·사각형·브러시·지우개로 분할 마스크를 그린다.
다각형 꼭짓점 이동, 마스크 농도, 실행 취소·다시 실행, 저장 후 이전·다음 이미지 이동을 지원한다.
기존 픽셀 마스크 위에도 그릴 수 있고, 저장한 다각형은 다시 열어 수정할 수 있다.
검출 박스 편집에는 이동·크기 변경·복제와 같은 연속 라벨링 흐름을 제공한다.
원본 해상도의 클래스 번호 PNG를 학습에 사용하며 기존 마스크·라벨은 트랜잭션 백업으로 보호한다.
[사용법과 단축키](DATASET_TEACHING.ko.md).

EfficientNet에만 표시하던 `val_loss` 제한을 제거했다. ResNet·ConvNeXt·DeepLab·U-Net의
기본 모델 학습도 선택 지표로 Best 체크포인트와 조기 종료를 판단한다. `val_loss`는 최소,
정확도·F1·Recall·mIoU·Dice는 최대이며 동점이면 최초 에폭을 유지한다.
Best 이벤트, 학습 이력과 결과의 지표 이름을 함께 저장한다. 다른 Best 기준으로 중단 학습을
이어가는 경우는 혼합하지 않고 안내한다. Custom CSP는 기존 공통 선정 로직을 사용한다.
PatchCore에는 에폭별 역전파·Val Loss Best가 적용되지 않는다. 외부 모델 팩의 학습 구현은
팩 제작자가 같은 설정 계약을 구현해야 한다.

LibreYOLO는 완성 팩이 없다는 현재 상태를 화면과 문서에 명시한다.
[`.dvmodel` 구성·설치·개발 절차](LIBREYOLO_MODEL_PACKS.ko.md)를 추가했다.

검증 범위: Best 최소 손실·동점·조기 종료, 실제 Qt 마우스 조작, PNG 저장·재열기·학습 로더,
저장 실패 복구, 웹 API와 브라우저 편집 흐름을 확인한다. Windows 실기기 검사는 CI와 별도다.
이번 변경은 ONNX 허용 오차·그래프 최적화 설정이나 기존 학습 가중치를 변경하지 않는다.
