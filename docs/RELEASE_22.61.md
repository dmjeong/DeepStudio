# 22.61 작업 폴더 삭제 후 모델 로드 복구

데스크톱 앱은 모델 확인과 추론을 별도 계산 프로세스에 맡깁니다. `jobs`에 이 작업의 요청, 상태, 판정과 미리보기 등을 저장합니다. 모델은 선택한 경로에서 읽습니다.

작업 기록을 삭제한 뒤 다시 모델을 열거나 추론하면 앱이 필요한 작업 폴더를 재생성합니다. 삭제한 결과를 보려면 다시 추론하세요. 진행 중이던 작업 폴더를 삭제하면 해당 작업의 결과가 유실될 수 있습니다. 계산 프로세스가 종료된 후에는 다음 작업을 시작할 수 있습니다.

C++ 암호화 배포 예제는 지정한 `.dvsenc`와 `.key`를 직접 읽습니다.
