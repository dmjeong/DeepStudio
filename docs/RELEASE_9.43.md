# 9.43 — 세그멘테이션 첫 클래스와 자동 배경 학습

Claude 브랜치 `2bfa569`(9.33)의 라벨링·영역 목록 개선을 기준으로 통합했습니다. 간단한 기능을 추가하는 릴리스이므로 +0.1을 적용합니다.

- 배경 ID 0 자동 예약. 사용자 첫 클래스는 ID 1부터 그리기·선택·저장할 수 있습니다.
- 기존 잘못된 첫 클래스는 Dataset의 **첫 클래스 복구**로 복구합니다. 기존 1번 이상 ID를 유지하며 원본을 백업합니다. 편집 이력이 없는 평면 배경 픽셀은 자동으로 결함으로 바꾸지 않습니다.
- 미라벨 이미지는 자동 배경으로 학습·검증에 포함합니다. 정상 이미지에 빈 마스크를 수동으로 만들 필요가 없습니다. UI에 자동 배경 개수를 표시합니다.
- SAM2도 배경 음성 프롬프트로 학습하고 ignore 픽셀을 보존합니다. 학습한 단일 마스크 출력을 ONNX에서도 사용하며, 재로드할 기반 가중치를 SHA256으로 확인합니다.
- 손상·크기 불일치·잘못된 클래스 마스크를 자동 배경으로 잘못 처리하지 않습니다. 중앙 크롭에도 같은 정책을 적용합니다.
- 통계 표의 클래스 이름이 잘리거나 설명과 겹치던 화면을 정리했습니다.
