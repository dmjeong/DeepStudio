# 검출·분할 데이터 티칭

Windows Qt 앱: 데이터셋 페이지에서 이미지를 선택하고 **데이터 티칭 / 정답 그리기**를 누른다.
이미지를 더블 클릭해도 열린다. 브라우저 UI: 데이터셋 이미지 썸네일을 클릭한다.
먼저 데이터셋 페이지에서 필요한 클래스를 추가한다. Qt 편집기에서는 클래스 추가도 가능하다.

## 검출 박스

사각형 도구로 드래그해 박스를 만든다. 선택 도구로 박스를 클릭한 뒤 안쪽을 드래그하면 이동하고,
꼭짓점을 드래그하면 크기가 바뀐다. 목록에서 클래스를 바꾸거나 Delete로 삭제한다.
Ctrl+D로 선택한 박스를 복제할 수 있다. 클래스별로 여러 객체를 표시하며, 저장 형식은
기존 `labels/<split>/<image>.txt`의 정규화된 `class cx cy width height`다.

## 분할 마스크

첫 클래스(번호 0)는 배경이다. 클래스 1 이상을 선택하고 윤곽을 클릭한다.
꼭짓점 3개 이상을 만든 뒤 Enter 또는 첫 점을 클릭해 다각형을 완료한다.
브러시로 칠하고 지우개로 배경으로 되돌릴 수 있다. 사각형도 마스크 영역으로 저장한다.
선택 도구에서 다각형 전체나 꼭짓점을 이동하고, 목록에서 영역별 클래스를 변경한다.
나중에 그린 항목이 이전 항목 위에 덮인다. 삭제하면 아래 항목 또는 원본 마스크가 드러난다.
마스크 농도 조절로 원본 경계를 확인한다.

정답은 `masks/<split>/<image>.png`에 **원본 해상도 uint8 클래스 번호**로 저장한다.
255는 학습 제외 영역이며 기존 마스크에 포함되어 있으면 유지한다. 지우개는 0을 그린다.
아무것도 그리지 않아도 저장하면 배경만 있는 정상 이미지의 정답으로 사용할 수 있다.
화면의 반투명 색상은 시각화용이다. 학습 PNG에는 색상 대신 클래스 번호가 들어간다.

PNG 안에 원본 래스터와 그리기 이력을 함께 기록하므로 저장 후 다시 열어 다각형 꼭짓점을
수정할 수 있다. 외부 도구로 수정하거나 클래스 번호를 일괄 바꾸면 새 픽셀을 우선하며,
맞지 않는 이전 다각형 이력은 적용하지 않는다. 외부 PNG의 윤곽을 자동으로 벡터화하지는 않는다.
기존 다각형 텍스트 정답은 열 때 읽고 저장할 때 PNG로 전환한다. PNG와 이전 텍스트가
중복 정답이 되지 않도록 이전 파일은 백업 후 정리한다. 저장 실패 시 이전 파일을 복원한다.

## 단축키와 연속 편집

| 키 | 동작 |
|---|---|
| P / R | 다각형 / 사각형 (분할) |
| B / E | 브러시 / 지우개 (분할) |
| V / H | 선택·수정 / 화면 이동 |
| Space+드래그 / 마우스 휠 | 화면 이동 / 확대·축소 |
| 0 | 화면 맞춤 |
| 1~9 | 클래스 번호 0~8 선택 |
| Enter / Backspace / Esc | 다각형 완료 / 마지막 점 제거 / 그리기 취소 |
| Delete / Ctrl+D | 선택 영역 삭제 / 검출 박스 복제 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+S | 현재 정답 저장 |
| J / K | 저장하고 이전 / 다음 이미지 |

Qt는 현재 분할의 이미지 순서, 브라우저는 현재 검색 결과 페이지의 이미지 순서로 이동한다.
저장이 실패하거나 미완성 다각형이 있으면 다음 이미지로 이동하지 않는다.
서버로 업로드하는 외부 라벨링 서비스가 아니라 로컬 프로젝트 파일을 편집한다.
Roboflow의 자동 라벨링·협업·SAM 자동 윤곽 생성은 이번 기능에 포함되지 않는다.
