# 21.47 Mask2Former 마스크 후보 수 설정

세그멘테이션 프로젝트의 학습 화면에서 **Mask2Former Swin-Small**을 선택하면 **하이퍼파라미터 → 마스크 후보 수**가 표시됩니다. 작은 결함 세 종류를 가르칠 때는 기본값 100과 16을 같은 데이터로 각각 새로 학습해 클래스별 검증 IoU를 비교할 수 있습니다.

같은 클래스의 영역이 여러 개 있어도 학습 정답은 한 장당 클래스별 마스크 하나로 묶습니다. 배경을 포함해 실제 한 장에 등장하는 클래스 수만큼은 후보를 확보해야 합니다. 저장한 모델을 다시 열거나 이어학습하면 학습 당시의 후보 수를 사용합니다.
