# 1.17 — 모든 내장 모델의 에폭 시간 표시

기본 모델(ResNet, ConvNeXt, DeepLab V3+, U-Net), EfficientNet, Custom CSP와
PatchCore의 학습 화면에 `최근 에폭 시간`과 `누적 시간`을 표시한다.

기본 모델의 에폭 시간은 실행 로그, 작업 이벤트, `training.json`, 체크포인트 이력에 함께
저장된다. 시간은 학습과 검증 구간을 의미하며, 체크포인트 저장과 최종 평가는 별도 단계다.

외부 Docker 모델 팩은 팩 구현이 에폭 진행 정보를 프로토콜로 제공하는 경우에만 그 값을
표시할 수 있다. 호스트는 팩의 최종 응답 시간을 에폭 시간으로 위장하지 않는다.

사용자 버전 규칙에서 화면 기능 추가에 해당하므로 1.07에서 **+0.1** 올려 1.17로 기록한다.
