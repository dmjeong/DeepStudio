# 14.86 — SEG 정답 기반 가상 불량 생성

신규 기능이므로 13.86에서 +1.0.

- Data Gen 첫 탭에서 프로젝트의 Train/Val 정답을 분석하고 가상 불량과 클래스 마스크를 함께 생성한다.
- crack·foreign material·shift·double·flip 지원. 실제 참조가 있는 사용자 클래스도 합성 방식을 지정할 수 있다.
- 8bit RGB/흑백, 원본 해상도, 얇은 결함 보존, 표면 정합, 합성 허용 영역, 기존 정답/255 제외 영역 보호.
- 원본/합성/참조 확대 비교, 마스크 수정, 개별 승인/제외, 기록 복원, 승인본을 포함한 새 학습 프로젝트 저장.
- Train/Val 교차 유입, 중복 원본, 손상 파일, 오래된 검수 내용의 덮어쓰기를 차단한다. 작업 중단 시 불완전한 결과를 게시하지 않는다.
- 추가 가중치·GPU·설치 패키지·외부 API가 필요 없다. 기존 모델의 학습/추론/ONNX 그래프는 변경하지 않는다.
