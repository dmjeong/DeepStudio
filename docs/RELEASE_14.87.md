# 14.87 — SEG 가상 불량 분석 0개 / 생성 무반응 수정 (+0.01)

- 분석·생성 실패를 화면 상단과 복사 가능한 비차단 오류 창에 표시한다. ‘분석 상세 / 오류 보기’, ‘내용 복사’를 추가했다.
- 실제로 읽은 Train/Val 폴더, 이미지 수, 정답 파일이 있는 이미지 수, 클래스별 불량 픽셀/영역/추출 수, 제외 사유를 남긴다. 분석 실패 보고서도 작업 폴더의 `segmentation-analysis.json`에 기록한다.
- 데이터셋 화면의 자동 스캔과 겹치면 최대 30초간 잠금 해제를 기다린 뒤 분석한다. 기다리는 동안 중단할 수 있다.
- 주변 다른 정답 때문에 제외되던 참조는 정상 문맥을 충분히 남길 수 있을 때만 문맥 폭을 줄여 다시 추출한다. 다른 클래스와 255 제외 영역은 복사하거나 배경으로 덮지 않는다.
- 재분석 또는 Train/Val 전환 시 사용할 수 있는 클래스를 다시 기본 선택한다. 같은 분석에서 사용자가 해제한 선택은 유지한다.
- 분석 실패 후 이전 분석을 자동으로 사용하지 않으며, 결과를 화면에서 읽지 못했는데 ‘완료’로 표시하는 경로를 막았다.

사용자는 **업데이트 후 프로젝트 정답 분석을 다시 실행**하면 된다. 기존 모델을 다시 학습할 필요는 없다. 그래도 0개라면 상단의 **내용 복사**로 정답 파일 누락/배경뿐인 정답/주변 정답 충돌/중복 이미지/경로 오류를 구분할 수 있다. 이미지 업로드는 필요 없다.
