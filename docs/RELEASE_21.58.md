# 21.58 CPU 비교와 분할 추론

**내보내기 → CPU 실행기·정밀도 비교 → 비교 시작**을 누르면 **전체 p50**과 **모델 p50**이 따로 표시됩니다. 전체 시간은 파일 읽기, 전처리, 모델 실행, 후처리를 포함합니다. FP32 JSON을 비우면 내보내기 화면에서 선택한 체크포인트로 임시 모델을 만듭니다. 이미 내보낸 ONNX를 측정하려면 해당 배포 JSON을 지정하세요.

원본 크기로 학습한 모델은 같은 가로·세로의 이미지로 측정합니다. 중앙 크롭을 사용한 모델은 해당 크롭을 포함하는 이미지를 사용합니다. 다른 크기의 이미지가 섞인 폴더는 제외된 파일을 로그에 표시하며, 맞는 이미지가 없으면 필요한 크기를 안내합니다. SAM2는 FP32 인코더와 이미지 중앙에 양성 점을 한 개 넣은 디코더의 합산 시간을 측정합니다.

예를 들어 640×640에서 2048×2048로 입력 크기가 바뀌면 모델이 처리하는 픽셀이 약 10.24배가 됩니다. 21.58은 분할 마스크의 클래스 선택과 결함 영역 후처리의 비용을 줄입니다. 원본 입력의 모델 실행 시간은 모델 구조와 검사 PC에 따라 달라집니다.
