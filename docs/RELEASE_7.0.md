# Deep Vision Studio Desktop 7.0

- 학습, 모델 검사와 추론을 별도 프로세스로 분리. 계산 프로세스 실패 시 GUI와 작업 로그 보존
- 추론 결과/Grad-CAM/가중치 및 입력 파일 해시 영구 저장, 재실행 후 작업 기록 열기
- 작업 ZIP 내보내기, 기간별 선택 삭제와 저장 용량 확인
- 데이터셋 스캔과 기본 썸네일 준비를 작업 스레드로 이동
- 이미지 확대/이동/화면 맞춤, 원본 픽셀 확인과 원본/결과 동기 비교
- 학습 설정 폼, 결과 차트/모델 비교, 실행 제어 모듈 분리
- 공식 사전학습 시작, 내 가중치 추가 학습, 중단된 last.pt 재개를 구분
- React와 공통 학습/추론/데이터 편집 엔진 및 프로젝트 왕복 저장 계약 동기화

Windows ZIP 전체를 압축 해제하고 `DeepVisionStudio.exe`를 실행합니다. `_internal` 폴더를 함께 유지해야 합니다. 배포 파일에 Python과 CPU 추론 런타임을 포함하며 별도 pip 설치가 필요하지 않습니다. GPU용 개발 환경은 기존 소스 실행 방식을 사용할 수 있습니다.

배포 태그는 `desktop-v7.0`입니다. 실제 ZIP을 한글/공백/괄호 경로에 풀고 Python 경로를 제거한 상태에서 GUI, 모델 검사, 독립 추론과 영구 결과 복원을 검증합니다.
