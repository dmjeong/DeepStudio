# Deep Vision Studio 20.23

Windows에서 U-Net ResNet18 등 기본 분할 모델의 원본 크기 GPU 학습은 자동 설정 시 현재 학습 프로세스에서 이미지와 마스크를 읽습니다. 2048×2048 배치를 여러 로더 워커가 공유 메모리에 미리 할당하면서 다음 에폭에서 Windows 오류 1455로 종료되던 경로를 제거했습니다. 시작 로그에 `workers=0`이 표시되며 모델 연산은 선택한 GPU에서 실행됩니다.

실패한 실행 폴더에 `last.pt`가 있으면 학습 화면에서 같은 모델의 **중단한 학습 재개**를 선택하고 그 파일을 지정하세요. 원본 크기와 판정 영역 설정은 이전 학습과 같아야 합니다.
