# Desktop 19.2

- Detection 박스를 클릭 후 드래그로 생성하며 십자선과 크기 미리보기를 표시합니다.
- 박스를 선택해 이동하고 모서리와 변의 8개 조절점으로 크기를 수정합니다.
- 큰 캔버스와 우측 객체 목록을 배치하고 선택을 연동합니다.
- 박스 생성, 이동, 크기 변경, 클래스 변경과 삭제에 실행 취소 및 다시 실행을 지원합니다.
- B 그리기, D 선택, H 또는 Space 화면 이동, Ctrl+휠 확대, Delete 삭제, Ctrl+Z 실행 취소, Ctrl+Shift+Z 다시 실행, 0 화면 맞춤을 제공합니다.
- 기존 다크 테마, OBB 편집 방식, 이전 모델 정답 형식을 유지합니다.
- Windows와 Linux의 마우스 조작 및 100%, 125%, 150% 배율 검증 후 소스 ZIP만 배포합니다.
