# Deep Vision Studio 9.7

PatchCore 모델을 로드한 뒤에도 '모델을 먼저 로드해 주세요'가 남는 문제를 수정합니다.

- PatchCore의 분류 클래스 목록이 null로 전달되어 GUI에서 len(None) 예외가 발생하는 원인 수정
- 클래스 목록이 없는 모델의 메타데이터를 빈 목록으로 정규화
- PatchCore 준비 완료 상태에 메모리 뱅크 크기, 백본, 실제 CPU/GPU 장치 표시
- 로드 결과를 검증한 뒤 활성 모델 교체. 잘못된 결과는 오류를 표시하고 기존 모델 유지
- 모델 검사와 실제 추론의 장치 선택 처리 통일
- 모델 로드 버튼을 눌러 별도 프로세스에서 검사하고 CPU 추론까지 수행하는 Qt 통합 검증 추가

기존에 저장한 best.pt를 그대로 사용합니다. 이 UI 수정 때문에 재학습할 필요는 없습니다.
