# Deep Vision Studio Desktop 10.8

추론 화면의 입력 영역과 결과 카드 때문에 배치 결과 표가 작게 보이는 레이아웃을 수정합니다.

- 모델 로드와 디바이스 선택을 작은 입력 영역으로 정리
- 데스크톱 우측의 독립 Result 카드를 제거하고 배치 결과에 전체 공간 배정
- 이미지 뷰어 최소 높이, 조작 버튼, 필터와 표 여백 축소
- 기존 표 정렬, 필터, 임계값 조절과 이미지 선택 유지
- 노트북 크기의 실제 Qt 테마 화면에서 표 높이와 화면 잘림 검증
데스크톱 배포 첨부는 Source.zip만 제공합니다.
