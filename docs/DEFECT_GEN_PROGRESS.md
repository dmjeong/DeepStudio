# Defect Gen 진행 기록

기준일: 2026-09-09

## 유지할 요구사항

- 데스크톱 브랜치: deep-studio-v0.0. React 브랜치: deep-studio-react.
- 공통 엔진과 데이터 형식을 함께 관리한다.
- 데스크톱은 소스코드에 태그를 붙여 배포한다. EXE 빌드와 실행 파일 업로드는 하지 않는다.
- 기능 추가는 +1.0, 버그 수정은 +0.1. 기존 태그를 덮어쓰지 않는다.
- 최종 목표는 실제 불량 형태를 학습하고 위치를 제어해 생성한 뒤 실제 검사 성능 개선을 확인하는 것이다.

## 현재 구현

후보별 독립 저장, 원본 스냅샷, 실제 변경 마스크, 생성 조건 기록, 검수 결과 재생성 없는 저장, 완료 후보 보존, 공통 작업 프로세스, 작업 복원, 별도 synthetic 출력이 구현되어 있다.

이번 변경은 텍스처 참조의 평가 데이터 유입 차단, 동일 파일 내용 중복 차단, 빈 폴더 탐색 차단, 잘못 겹친 분할 차단 및 배치 공개/재사용 시 전체 저장 묶음 검증이다.

현재 중복 검사는 선택된 원본의 파일 바이트 해시 기준이다. 재인코딩된 복제 이미지, 다른 위치로 복사된 평가 이미지의 출처, 동일 제품/로트의 관련성까지 확인하는 데이터 분할 검증은 아직 없다.

현재 마스크는 실제 변경 픽셀이다. 허용 영역, 생성 요청 마스크, 실제 변경 마스크, 검수된 불량 정답은 서로 다른 자료로 관리해야 하며 네 종류의 영구 저장과 라벨 편집은 추가 구현 대상이다. 변경 마스크를 바로 학습 정답으로 취급하지 않는다.

## 확인한 범위

- 공통 트랜잭션 테스트 14개 통과. PNG 인코더는 테스트에서 Pillow로 대체한다.
- 저장 단계 실패 주입과 원본/ZIP/기록 누락 재현은 실제 임시 파일로 확인한다.
- 데스크톱 소스 배포 YAML과 포함된 Bash 구문 확인.
- 현재 실행 환경에 pytest, OpenCV, PySide6, PyTorch가 없고 패키지 설치도 완료하지 못했다. 전체 테스트 및 실제 GPU 검증 미완료.
- 두 UI의 실제 실행, Windows 동작, 실제 OpenCV 코덱 검증은 CI 결과와 구분해 확인해야 한다.

## 이어갈 순서와 통과 조건

1. 공통 기반 검증: OpenCV 실제 파일 입출력, UI에서 생성/검수/취소/재실행, 강제 종료 후 완료 결과 복원. 실패 케이스가 남으면 AI 생성 단계 완료로 넘어가지 않는다.
2. 평가 데이터 고정: 대표 제품과 실제 불량 한 종류, 허용 크기/위치, GPU 모델과 VRAM, 목표 미검/과검 수치를 확보한다. 제품 개체, 로트, 촬영 시점별로 분리하고 원본/패치 중복을 차단한다.
3. 생성 방식 비교: 규칙 합성, 실제 불량 조각 합성, SDXL Inpainting과 불량별 LoRA 후보를 같은 데이터로 비교한다. 현재 후자의 두 방식은 미구현이다.
4. AI 학습: 실제 GPU에서 학습, 저장, 이어학습, 재로드, 생성, 취소 후 재실행을 확인한다. GPU 검증 없이 완료로 표시하지 않는다.
5. 검수/반영: 네 마스크의 의미를 구분하고, 원본과 같은 배율로 비교하며, 승인/제외와 정답 라벨 수정을 기록한다. 승인한 실제 파일만 학습 데이터에 반영한다.
6. 성능 평가: 실제 데이터만 / 규칙 합성 추가 / 불량 조각 추가 / AI 생성 추가의 네 조건을 초기 가중치, 학습 스텝, 기본 증강, 평가 데이터 고정 후 최소 세 시드로 비교한다. 최종 평가는 실제 이미지만 사용한다.

허용 영역 밖 픽셀은 원본과 동일해야 한다. PatchCore 정상 학습에는 합성 불량을 넣지 않는다. AI 생성은 먼저 8비트 RGB/흑백으로 검증하고 16비트 높이 데이터의 물리값 보존을 별도 과제로 남긴다.
