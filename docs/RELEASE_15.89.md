# 15.89 — 모델 추가 후 회귀 오류 수정

- EoMT: 입력 크기가 14의 배수가 아닐 때 쿼리 학습 마스크를 패딩 좌표계로 복원한 뒤 원본 영역만 비교한다. 640 입력에서도 얇은 결함 정답이 늘어나거나 줄어들지 않는다.
- 학습 화면: EfficientNet·LibreYOLO 재개는 저장된 스케줄을 유지하고, 총 에폭 연장이 가능한 기본 모델 재개만 에폭 입력을 허용한다.
- 배포 검사: Python과 C++ ONNX Runtime을 1.29.0으로 통일하고 실제 로드된 DLL/라이브러리 버전을 검사한다. 서로 다른 버전을 비교하고 동일 배포라고 보고하지 않는다.
- Windows 검사: CMake가 설치된 패키지가 없는 다른 Python을 선택하지 않도록 검사 인터프리터를 명시한다. 예제·수치 검사 환경의 OpenCV/SciPy 누락을 보완한다.
- 웹 배포: 새 모델의 timm/SciPy 의존성을 포함한다. Playwright 검사는 지원되는 Ubuntu 24.04에서 실행한다.
- 화면 검사에도 앱과 같은 스타일시트를 사용해 화살표 아이콘을 표시한다.

검증 결과는 [회귀 검사 보고서](03-analysis/modern-dense-regression.md)에 기록한다. 합성 데이터 검사는 실제 불량 검출 정확도나 Windows 검사 PC 속도 보증이 아니다.

EoMT의 기존 체크포인트는 계속 열 수 있다. 640 등 14의 배수가 아닌 크기에서 잘못 정렬된 보조 손실의 영향을 받았다면 수정 버전으로 학습하고 검증셋에서 다시 평가한다. 다른 모델이나 448 입력의 기존 가중치를 이 수정 때문에 다시 학습할 필요는 없다.
