# 9.44 — 데이터셋 화면의 첫 클래스 누락 수정

버그 수정 +0.01.

- 등록 클래스 표시와 영역 편집용 클래스 목록을 분리했습니다. 데이터셋 통계·필터에는 첫 항목과 이미지가 0장인 클래스까지 모두 표시합니다.
- 배경 행은 실제 배경 픽셀이 있는 이미지와 미라벨 자동 배경 이미지의 수를 보여줍니다. 배경은 blob으로 세지 않습니다.
- 구형 프로젝트에서 첫 결함 이름이 배경 ID 0에 저장된 경우, 이름을 숨기지 않고 **복구 필요**를 표시합니다. 상단 안내와 **첫 클래스 복구** 버튼으로 기존 백업·복구 기능을 사용할 수 있습니다. 복구 전에는 배경을 결함 통계로 오인하지 않습니다.
- 데이터셋 화면을 여는 것만으로 원본 마스크나 저장된 클래스 번호를 바꾸지 않습니다. 복구 후에도 해당 클래스의 필터 선택을 유지합니다.
