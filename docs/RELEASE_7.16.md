# 7.16 — BW8 정규화 LUT 최적화

BW8 전처리기에서 가능한 uint8 픽셀값 256개의 정규화 결과를 한 번 계산하고,
리사이즈 뒤 LUT 조회로 사용한다. 1채널 경로는 별도 루프를 사용한다.
`channel_count_`는 입력 mean의 채널 수로 초기화하고 `<array>`를 헤더에서 포함한다.

기존 코드를 기준으로 1/3채널, 중앙 crop 사용/미사용 네 조합을 317×263 입력
(stride 336), 224×224 출력으로 비교했다. 네 경우 모두 출력 원소 차이는 0이었다.
로컬 Clang `-O3` 결과는 1채널 약 1.42배, 3채널 약 1.05~1.06배 빨랐다.
이 속도는 로컬 측정값이며 VS2017/Windows 성능 측정은 아니다.
