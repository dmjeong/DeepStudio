# Deep Vision Studio React 12.6

추론 우측 결과를 정렬과 필터가 가능한 표로 개선합니다.

- 인덱스, 데이터셋 클래스, 파일명, 판정, 스코어, 추론 시간 표시
- 숫자 기준 스코어/시간 정렬, 클래스와 판정 필터, 파일명 검색
- 체크한 행만 보기, 표시 행 선택, 선택 해제
- Anomaly 임계값 숫자 입력과 슬라이더. 스코어가 임계값 이상이면 NG
- 저장된 임계값 복원. 임계값이 없는 결과는 사용자 설정 전까지 미보정으로 유지
- 임계값 변경 시 표, 이미지 판정과 결과 카드 갱신. 추론 재실행 없이 기존 스코어와 시간 보존
- 정렬/필터 후에도 파일 식별자로 미리보기 연결
- 저장 결과에 데이터셋 원래 클래스 기록. 확인할 수 없는 클래스는 빈 값으로 유지

조절한 임계값은 현재 결과 검토에 적용합니다. 모델 체크포인트와 저장된 원본 결과는 수정하지 않으며, 다른 모델이나 작업을 열면 저장된 기준으로 시작합니다.

검증에는 임계값 경계, 오류 결과 보존, 숫자 정렬, 필터 조합, 실제 Qt 선택과 기존 캐시 재사용을 포함합니다.
React는 결과 전체를 정렬/필터한 뒤 페이지를 나누며, 실제 배포 ZIP의 브라우저 검증을 포함합니다.
