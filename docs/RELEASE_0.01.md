# 0.01: 빈 검증 폴더 학습 분할 수정

새 분류 프로젝트는 `train`과 `val` 클래스 폴더를 함께 만든다. 이전에는 사용자가 Dataset 화면에서 TRAIN에 이미지만 추가하면, 빈 `val` 폴더를 명시적 검증 세트로 잘못 판단해 데이터 로더가 실패했다.

이제 `val`에 이미지가 없으면 TRAIN 이미지를 프로젝트의 검증 비율로 자동 분할한다. 따라서 적은 데이터도 마지막 배치를 버리지 않고 학습과 검증을 모두 시작할 수 있다.

데이터 경로·이미지 형식·정답 쌍의 문제가 남아 있으면, 이전의 포괄적인 “학습 가능한 데이터 배치 없음” 대신 실제 데이터 로더 오류를 함께 표시한다.
