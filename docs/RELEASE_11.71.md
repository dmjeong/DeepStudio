# Deep Vision Studio Desktop 11.71

PatchCore의 특징 집계 순서 및 새 판정 기준의 경계값을 수정했습니다(+0.01).

## 변경 이유

224×224 패치를 이미 사용하는 경우에도 특징 집계가 검출 성능에 영향을 줬습니다. 기존 코드는 낮은 해상도 특징을 먼저 확대하고 평균을 냈습니다. 수정 후에는 Anomalib처럼 각 레이어의 원래 격자에서 평균을 낸 뒤 확대·결합합니다. `layer2/3`, 백본 가중치와 특징 차원은 그대로입니다.

검증 F1이 최적인 임계값을 검증 이미지의 점수와 정확히 같게 두면, 매우 작은 ONNX 수치 차이로 해당 이미지의 판정이 바뀔 수 있었습니다. 새 보정에서는 검증셋 판정을 유지하면서 인접 점수 사이에 FP32로 표현 가능한 기준을 둡니다. 미래 영상의 판정 일치를 보장하는 방법은 아니며, 간격이 없으면 임계값을 임의로 움직이지 않습니다.

## 적용 방법·호환성

- 정상 데이터로 **새 뱅크 구축**을 실행하고 정상·불량 검증 데이터로 판정 기준을 다시 보정합니다.
- 이전 `.pt`를 열거나 ONNX만 다시 내보내면 기존 특징 집계를 유지합니다. 수정된 특징 공간에는 메모리 재구축이 필요합니다.
- 기존 `.pt`에서 **추가 학습**하면 기존 집계를 보존합니다. 기존 백본에서 **새 뱅크 구축**하면 새 집계를 사용합니다.
- 새 로그의 `특징 집계: pool_then_align_v2`로 적용 여부를 확인할 수 있습니다.
- 새 `.pt`는 schema 6입니다. 구버전 앱은 새 파일을 읽을 수 없으며, 업데이트된 앱은 schema 1~5도 읽습니다.
- ONNX 입출력 형식은 동일하여 기존 C++ 로더를 사용할 수 있습니다. 새 학습 결과의 ONNX와 JSON을 함께 교체하세요.

## 검증 범위

합성 RGB 트레이의 고정 224 격자, 정상 학습 4장, 검증·정상 보정 각 2장, 시험 10장을 사용했습니다. ResNet18 사전학습 가중치, 메모리 1,024개, seed 0입니다. 검증 점수 사이 보정 기준을 양쪽에 동일하게 적용하면:

| 집계 방식 | 불량 패치 검출 | 정상 패치 오검출 |
|---|---:|---:|
| 기존 집계 | 15/33 | 9/1,087 |
| 수정 집계 | 23/33 | 0/1,087 |

시험 자료는 이전 진단에서도 사용한 합성 데이터이며, 모델 선택을 독립적으로 검증하는 새 생산 시험셋이 아닙니다. 33개는 결함 픽셀을 포함한 **패치 수**로, 실제 결함/칩 개수와 다릅니다. 수정 후에도 10개를 놓쳤으므로 사용자 검출 문제가 모두 해결됐다고 주장하지 않습니다.

제품 코드의 336패치 점수가 개선 실험 코드와 정확히 같았습니다. 공식 사전학습 모델을 저장·복원·ONNX 내보내기 후 정상/불량 14패치에서 실제 C++ 점수·지도·판정을 확인했습니다. PyTorch↔ORT 원시 점수 최대 오차 약 `1.79e-6`, 지도 약 `6.38e-6`이며 수정된 기준에서 판정은 일치했습니다. macOS CPU 검사이며 Windows와 사용자 비공개 영상은 미검증입니다.
