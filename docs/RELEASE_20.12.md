# Deep Vision Studio 20.12

**모델 내보내기 → CPU 실행기·정밀도 비교**를 열고 FP32 배포 JSON과 시험 이미지 폴더를 선택합니다. ONNX 파일은 JSON이 가리키는 위치에 두세요. 실행기는 기본값인 **ONNX Runtime + OpenVINO**를 선택하고, 스레드 수는 `1, 2, 4, 8`처럼 입력합니다. `0`은 각 실행기의 자동 설정입니다.

FP32는 항상 비교합니다. FP16과 INT8은 체크박스로 선택합니다. 기존 FP16·INT8 JSON을 사용하거나 비교용 그래프를 임시로 만들 수 있습니다. EfficientNet B0/B1의 INT8 비교용 그래프에는 정상과 불량이 섞인 보정용 이미지 폴더가 필요합니다. 시험 폴더는 따로 지정하면 양자화에 쓰지 않은 영상에서 판정 차이를 확인할 수 있습니다.

결과표에는 전체 p50·p95, 모델 p50·p95, 같은 스레드 수의 기준 FP32 대비 출력 차이가 나옵니다. 두 실행기를 선택하면 ONNX Runtime FP32가 기준입니다. 전체 시간은 이미지 파일 읽기부터 후처리까지 재고, 모델 시간은 그 이미지에 대한 모든 런타임 호출을 더합니다. 행에 마우스를 올리거나 로그를 보면 런타임 버전과 실행 설정을 확인할 수 있습니다.

정밀도 열은 ONNX 그래프의 형식을 표시합니다. OpenVINO CPU는 부동소수점 실행에 FP32 힌트를 지정하고, QDQ 그래프는 CPU에서 지원하는 정수 연산을 사용할 수 있습니다. FP16 연산도 CPU에 따라 FP32로 실행될 수 있습니다. [OpenVINO CPU 정밀도 문서](https://docs.openvino.ai/2026/openvino-workflow/running-inference/inference-devices-and-modes/cpu-device.html).

설비의 EROIBW8 메모리 입력은 이미지 파일 읽기 시간이 없습니다. 실제 검사 시간은 대상 PC의 Release C++에서 전처리부터 판정까지 재세요. 비교 결과의 Top-1 변경 수는 기준 모델과의 판정 차이입니다. 실제 미검과 오검출은 정답을 붙인 시험 영상에서 확인하세요.
