# 통합 및 평가 설계

1. 충돌 해결: main의 기존 DINOv2 ID/체크포인트, 미라벨 배경 학습, 전경 표시와 정답 평가를 보존하면서 Claude 신규 모델·패치·판정 규칙·취소 및 가중치 가져오기를 통합한다.
2. 평가 예제: example/cpp/segmentation_eval. VisionInference::Segment를 재사용해 ONNX JSON 전처리/크롭/패치/규칙을 실제 배포와 일치시킨다.
3. exe 옆 evaluation.json에서 모델 JSON, 이미지/마스크 폴더, 반복 수를 읽는다. 상대 경로는 설정 파일 위치 기준이다. 모델 준비 및 워밍업은 측정에서 제외한다.
4. 정답은 0=배경, 나머지는 export 클래스 순서, 255=무시. 누락 정답은 기본 실패; 크기/클래스 범위 불일치는 실패. GT를 예측 크기로 축소하지 않는다. 크롭이면 예측과 동일한 원본 영역으로 GT만 자른다.
5. 데이터셋 전체 혼동행렬을 합산한다. union=0은 null로 보고하고 평균에서 제외한다. GT가 없지만 오검출된 클래스는 IoU=0으로 포함한다. 배경 포함/제외 mIoU를 별도 기록한다.
6. 검증: 클래스별 TP/FP/FN 수식 테스트, ignore/없는 클래스/잘못된 마스크, 실제 합성 체크포인트 export→C++ 평가와 Python 비교. 관련 기존 회귀 실행.
