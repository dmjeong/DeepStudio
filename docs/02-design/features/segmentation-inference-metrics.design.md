# 설계

1. 순수 평가 모듈이 프로젝트 스냅샷과 이미지의 split-relative 경로로 정답을 찾는다. 동일 파일명의 다른 폴더/프로젝트 이미지는 연결하지 않는다.
2. PNG 우선, 없으면 기존 라벨링 폴리곤 렌더러 사용. 정답의 원본 크기/정수 ID/클래스 이름 순서 검증. 손상/불일치 사유는 평가 오류로 분리하며 추론은 유지한다.
3. 예측만 원본 정답 해상도로 nearest 확대한다. 중앙 크롭이면 해당 영역만 평가. 255 제외, 정답 픽셀 0인 클래스는 평균에서 제외한다.
4. InferenceResult.details.segmentation_evaluation에 지표, 클래스 이름, 교집합/합집합/정답/예측 픽셀 수, 비교 범위/소스/시간 기록. 원본 마스크는 결과에 보관하지 않는다.
5. 판정 상세는 클래스명·IoU·Dice·픽셀 분포 표시. 배치는 개별 mIoU/Dice와 평가 상태, 필터와 무관한 전체 배치 클래스별 누적 표. 기존 스코어/추론 시간 의미 유지.
6. 전체 배치 지표는 이미지별 IoU 평균이 아니라 원소별 카운트 합산. 이름 계약이 다른 결과는 합산하지 않는다. 과거 JSON은 평가 미실행으로 표시하며 저장된 결과를 다시 추론하지 않는다.
7. 수작업 정답 계산, 크롭/리사이즈/ignore/미라벨/손상/이름불일치/폴리곤/프로세스 전달/Qt/캐시 복원 회귀 검증.
