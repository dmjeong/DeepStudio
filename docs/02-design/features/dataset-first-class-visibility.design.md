# 데이터셋 첫 클래스 표시 수정 — 계획 및 설계

## 재현과 범위

9.43의 DatasetWidget이 등록 목록에도 `region_classes()`를 사용해 세그멘테이션의
첫 이름을 무조건 제외한다. 새 프로젝트의 배경도, 구형 프로젝트의 잘못 등록된
첫 결함 클래스도 화면에서 사라진다. 이번 수정은 데이터셋 UI의 목록·통계·필터다.

## 표시 계약

- 통계와 필터에는 등록된 클래스 전부를 원래 순서로 표시한다. 이미지가 0장이어도 유지한다.
- 영역 변경·삭제 후보는 기존대로 전경 클래스만 사용한다. 배경 ID 0을 결함으로 그리지 않는다.
- 정상적인 배경 클래스 행은 배경 픽셀이 있는 이미지와 자동 배경 이미지를 센다.
  이때 배경을 blob 수로 계산하지 않으며, 오류/ignore-only/전경만 있는 이미지는 제외한다.
- 구형 프로젝트에서 0번에 결함 이름이 저장된 경우 이름을 숨기지 않고 `복구 필요`를 표시한다.
  배경 픽셀 수를 그 결함의 영역 수로 잘못 보고하지 않는다. 해당 필터에서도 이유와 복구 버튼을 안내한다.
- 단순 화면 진입은 프로젝트·마스크를 변경하지 않는다. 기존 백업 가능한 `첫 클래스 복구`를 실행하면
  같은 이름의 필터를 유지하면서 복구된 실제 영역을 다시 표시한다.

## 검증 계획

실제 Qt 위젯에서 새 프로젝트, 재개한 구형 프로젝트, 이미지 없는 클래스, 배경/전경/ignore/오류 마스크,
미라벨 이미지, 복구 전후 필터와 정답 파일 보존을 확인한다. 탐지의 ID 0은 계속 일반 클래스다.
기존 라벨링/데이터셋 회귀 테스트 및 전체 Python 테스트를 실행한다. Windows 실기 확인은 별도다.
