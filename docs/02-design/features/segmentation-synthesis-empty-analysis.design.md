# 14.87 — SEG 합성 분석 0개 / 무반응 수정

사용자는 분석 후 Train 참조가 전부 0이며 생성 버튼에 반응이 없다고 보고했다.
현재 사용자 PC의 오류 로그/마스크는 없으므로 그 데이터의 직접 원인은 미확정이다.

확인한 코드 결함:
- 데이터셋 자동 스캔이 잠금을 잡고 있으면 분석이 대기 없이 즉시 실패한다.
- 분석 실패를 화면 하단 QLabel에만 표시한다. 분석 단계의 경로/정답 수/제외 이유를 남기지 않는다.
- 실패 시 이전 분석을 다시 선택할 수 있고, refresh 실패를 잡은 뒤 완료 문구로 덮어쓴다.
- 참조 0개 클래스 체크는 해제하지만 재분석/Train↔Val 전환 뒤 생긴 참조는 다시 선택하지 않는다.
- 한 결함 주변에 다른 클래스가 1픽셀만 있어도 참조 전체가 제외된다. 제외 세부 사유 없이 0개가 될 수 있다.

수정 범위:
0. 분석 워커에서 데이터셋 잠금 해제를 최대 30초 기다린다. 진행 안내 및 중단을 지원한다.
1. 분석 상태/오류를 상단에 고정 표시하고 버튼/작업 실패를 복사 가능한 비차단 오류 창으로 표시.
2. 분석한 폴더, 이미지 수, 정답 파일 수, 클래스별 정답/추출 수, 제외 이유를 성공/실패 모두 전달.
   실패 보고서는 작업 기록에 남기되 사용할 수 없는 부분 분석을 정상 profile로 게시하지 않는다.
3. 실패한 분석은 생성에 사용하지 않는다. 새 분석/분할에서는 사용 가능한 클래스를 기본 선택한다.
4. 가까운 다른 정답 때문에 실패하면 정상 문맥이 충분히 남는 범위에서만 문맥 폭을 줄여 재시도.
   불량 영역/255를 삭제하거나 다른 클래스를 배경으로 바꾸지 않는다. 복구 불가 사유를 표시한다.
5. Qt 실제 버튼 클릭, 분석 실패/복구, Val 전환, 새 profile 선택, 상태 복사 및 상세 기록을 회귀 검사.

원래 데이터 분할·출력 해상도·추론 모델은 유지한다. Windows 현장 데이터의 원인을 임의로 단정하지 않는다.
