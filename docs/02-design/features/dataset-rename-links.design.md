# 데이터셋 정답 연결 복구 설계

1. 공통 semantic 파일 인덱스에서 이미지·마스크·미연결 마스크를 조회한다. 로더의 엄격한 누락/중복 검사는 유지하고 이름 변경 및 복구 위치를 설명한다.
2. 데이터셋 스캔 결과에 `orphan_masks`를 포함한다. 화면 상단에 개수/설명/`정답 연결 복구` 버튼을 표시한다. 복구 창은 같은 분할의 이미지와 옛 마스크를 명시적으로 선택하고 원본 위에 정답을 미리 표시한다. 자동 선택·추측 연결은 하지 않는다.
3. `rename_image`는 현재 이미지와 모든 동반 정답을 함께 이동한다. `relink_mask`는 선택한 미연결 마스크(동반 폴리곤 포함)를 새 이미지 이름으로 이동한다. 모두 `EditTransaction` 내에서 수행하며 크기·클래스·경로·기존 정답 충돌을 검사한다. 원본 백업, 부분 실패 시 복구를 보장한다.
4. 프로젝트 저장 후 SEG 데이터셋 스캔을 갱신한다. 이미지 우클릭에 정답 동반 이름 변경을 제공한다. 복구 후 스캔/클래스 통계를 다시 계산한다.
5. 변경은 파일 연결·UI에 한정한다. 학습/추론/ONNX 모델 수식과 성능에 영향 없음. 사전 기록 없는 외부 이름 변경의 정답을 순서·크기만으로 추측하지 않는다.

추가: 패키지 복구는 앱이 사용하는 Python의 `-m pip`를 실행하고 기존 torch/torchvision/numpy 버전을 constraints로 고정한다. `--no-deps`를 제거해 timm의 하위 의존성도 설치한다. 가중치 다운로드와 EXE 빌드는 수행하지 않는다. 실패 시 성공으로 표시하지 않고 종료 코드 1을 반환한다. 공통 모델 생성 경로의 오류에 해당 Python 절대 경로를 포함한다. SCTNet의 DropPath는 샘플별 Bernoulli/scaling을 동일하게 유지하며 체크포인트 키와 eval/ONNX 그래프를 변경하지 않는다.
