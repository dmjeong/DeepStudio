# 14.86 — SEG 정답 기반 가상 불량 생성

신규 기능 +1.0. 기존 LoRA/규칙 Data Gen과 함께, 프로젝트의 train/val 정답을 바로 사용하는
CPU 기반 참조 합성 경로를 제공한다. 클래스는 crack/FM/shift/double/flip 모두 지원한다.

## 데이터 계약

- PNG 클래스 인덱스 마스크 또는 기존 폴리곤 정답을 읽는다. 0은 배경, 255는 제외 영역이다.
- train/val/test 원본과 정답을 로컬 스냅샷으로 고정하고 SHA256을 기록한다. 원본은 변경하지 않는다.
- train 참조+train 바탕만 학습용 생성에 사용한다. val 참조+val 바탕은 검수용 생성 전용이며
  학습 데이터셋 게시를 거부한다. test는 최종 데이터셋 복사와 분할 중복 검사에만 사용한다.
- 클래스 순서와 원본 픽셀 크기를 유지한다. 생성 마스크는 변경 픽셀 마스크와 분리한다.
- 출처, 클래스, 변형, 위치, 시드, 품질 수치, 검수 상태를 보존한다.

## 합성

1. 정답 연결 영역에서 실제 결함과 주변 표면을 추출한다. 클래스별 표본 수·면적·크기를 표시한다.
2. crack은 주변 표면을 추정해 결함 잔차를 이식한다. FM은 색상·윤곽을 보존해 이식한다.
3. shift/double/flip은 주변 배치를 포함한 영역을 그대로 이식한다. 회전/반전/크기 변형을 하지 않는다.
4. 원본 좌표와 유사 표면 탐색으로 위치를 고른다. 기존 정답·255·선택 허용 영역을 침범하지 않는다.
5. 제한된 변형, 밝기 정합, 경계 처리 후 클래스 마스크를 같은 좌표에 합성한다.
   1~2px 얇은 결함은 축소/회전하지 않고 전체 영상도 축소하지 않는다.
6. 유효 위치/시각 변화가 부족하면 명시적으로 제외한다. 억지로 성공 처리하지 않는다.

## UI 및 저장

Data Gen의 세그멘테이션 전용 첫 탭: 정답 분석 → 클래스/생성 수/방식 선택 → 후보 생성 →
원본/합성/마스크 비교 → 마스크 수정 및 승인 → 승인본을 포함한 새 학습 프로젝트로 저장.
기존 프로젝트/val/test는 그대로 두고 새 버전에는 원본 데이터와 승인 train 합성본만 함께 넣는다.
Val 합성본은 검수만 가능하며 별도 stress-test 자료로 남는다. 별도 모델/가중치/네트워크가 필요 없다.
CPU 작업은 기존 독립 프로세스 관리자를 사용하고 중단과 재실행/검수 복원을 지원한다.

## 확인

5개 클래스의 합성·정답 정합·tiny crack·기존 결함/255 보존·재현성·분할 격리·중복 원본·
손상 파일·취소·게시 원자성·GUI 버튼과 검수 복원을 검사한다. 게시 데이터로 실제 패치 학습한다.
3500×1500급 합성 트레이로 생성 예시를 렌더링해 검토한다. 실제 검사 데이터의 품질 개선은
사용자 실데이터 비교가 필요하며, 생성 성공이나 학습 실행을 정확도 개선으로 보고하지 않는다.
