# 세그멘테이션 비교 모델 추가

요청: 사용자가 같은 데이터로 학습하고 평가할 수 있도록 U-Net MobileNetV4 Conv-S,
U-Net ShuffleNetV2 x1.0, U-Net EfficientNet-B1, BiSeNetV2, STDC1을 기본 모델에 추가한다.

## 구현 계약

- Docker 팩 없이 데스크톱에서 선택한다. 마스크의 0은 배경, 255는 학습 제외.
- U-Net 3종은 사전학습/로컬 가중치/처음부터 학습을 지원한다.
  MobileNetV4-S와 B1은 Apache-2.0 표시된 timm 가중치를 고정 revision/SHA256으로 받는다.
  ShuffleNetV2는 torchvision 공식 파일을 사용한다. build.bat과 가중치 준비 배치에 연결한다.
- BiSeNetV2/STDC1의 MIT 코드를 고지와 함께 포함한다. 출처/사용 조건이 불명확한 외부
  분할 가중치를 자동 다운로드하지 않는다. 처음부터 학습과 Studio 체크포인트 추가 학습은
  기본 제공한다. 이 두 모델의 기본 사전학습 파일이 없음을 선택 화면에 명시한다.
- BiSeNetV2 보조 분할 손실, STDC1 보조 분할/경계 손실은 학습에만 사용한다.
  검증 지표와 ONNX 출력은 주 분할 결과만 사용한다.
- 1/3채널, 클래스 변경 추가 학습, 배치 1, 패치 학습, 증강, best 지표/CSV를 지원한다.
- 추론 출력은 기존 [N,C,H,W] logits 계약이다. C++/암호화 경로를 공유한다.
  원본 ROI를 32의 배수로 패딩하고 전체 추론하는 기존 CNN 동작을 유지한다.
  B1/BiSeNetV2/STDC1의 전역 평균 문맥은 입력 범위에 영향을 받으므로 실제 ROI로 품질 평가한다.
- 모델 추가 릴리스는 13.84(+1.0). 기존 체크포인트 구조와 기존 모델 동작을 유지한다.

## 검증

5종 각각 순전파/역전파, 배치 1, RGB/흑백, 홀수 크기, 학습/검증 1에폭,
best 저장·재로드·클래스 변경, 실제 Qt 선택/학습 모드, ONNX FP32 및 양자화,
C++ 분할 로더/암호화 산출물 연동을 검사한다. 세 U-Net의 실제 공식 사전학습 파일도 로드한다.
Windows/CUDA 실측 여부와 개인 검사 데이터 정확도는 로컬 테스트와 구별한다.
