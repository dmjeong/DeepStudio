# Segmentation Release 구간 측정

- 사용자: Release에서 전체 약 1.2초. 모델 계산과 후처리 중 실제 지연 위치를 구분해야 한다.
- `SegmentResult`에 전처리·모델 실행·출력 검증·클래스/확률 계산·결함 판정·결과 이미지 생성 시간을 추가한다.
- 단조 시계 `std::chrono::steady_clock`으로 인접 경계만 기록한다. 출력이나 파일 쓰기는 측정 안에 넣지 않는다. 추론 계산·스레드·임계값은 유지한다.
- 전처리 시간은 ROI 선택, 색 변환, 크기 조정, 정규화 및 ORT 입력 래퍼 준비를 포함한다. 모델 시간은 `Session::Run` 호출 구간이다.
- `inference_ms`는 기존처럼 SDK 내부 합계이며 반환 시 로컬 버퍼 해제와 호출자 결과 대입은 제외한다. 호출부 실측 `call_total_ms`와 구별한다.
- `postprocess_ms`는 검증·decode·rules·render 합계다. 총합에 다시 더하지 않는다.
- 무인자 `segmentation_eval` 예제에 반복별 구간 기록을 추가한다. 콘솔은 전체 호출 중앙값에 가장 가까운 실제 반복 한 회의 구간을 표시한다. 독립적인 구간 중앙값을 합쳐 가상의 결과로 표시하지 않는다.
- 회귀: 모든 구간의 유한·음수 아님·합계 일치, SDK 분할 결과 유지, 예제 JSON 기록·워밍업 제외. 새 C++ 결과 필드 때문에 SDK와 호출 프로젝트 모두 재빌드한다. C ABI 구조는 변경하지 않는다.
