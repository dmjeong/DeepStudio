# 라벨링 작업실 구현 설계

작성일: 2026-10-22. 계획: [annotation-workspace](../../01-plan/features/annotation-workspace.plan.md).

## 구성

- `annotation_workspace.py`: Detection과 Segmentation의 공통 PySide6 작업창. 클래스, 객체 선택, 이력, 저장, 초안, 탐색, 격자, AI 제안을 연결한다.
- `annotation_workspace_ui.py`, `annotation_workspace_state.py`: 화면 구성과 저장·Undo·탐색 상태를 분리한다. `annotation_shortcuts.py`는 캔버스 단축키, `annotation_grid_dialog.py`는 격자 미리보기, `annotation_io.py`는 백그라운드 IO를 담당한다.
- `detection_canvas.py`, `segmentation_canvas.py`: 원본 픽셀 좌표에서 포인터 동작을 처리한다. 표시와 학습 데이터를 분리한다.
- `mask_annotations.py`: v1 호환 읽기, 객체 식별자, 범위 제한 지우기, 래스터 영역, 마스크/소유 영역 캐시를 관리한다.
- `annotation_tools.py`: UI와 독립적인 격자 좌표·초안·원자 저장을 제공한다.
- `annotation_assist.py`: 설치된 SAM2 자산을 사용하는 취소 가능한 로컬 보조. 이미지/revision이 달라진 응답은 폐기한다.
- `annotation_journal.py`: 프로젝트 잠금과 중단된 데이터 편집 트랜잭션을 복구한다.

## 데이터와 호환

Detection의 정답은 기존 정규화 TXT, Segmentation은 원본 해상도의 클래스 번호 PNG다. 편집용 숨김은 학습 픽셀을 바꾸지 않는다. 잠금은 편집을 막는다. PNG의 새 편집 메타데이터는 기존 v1을 읽고, 외부 변경된 PNG는 실제 픽셀을 우선한다. 지우기는 배경 0이고 학습 제외 영역은 255다.

브러시를 이어 그리면 선택 객체 ID에 묶는다. 가져온 PNG는 클래스별 래스터 영역으로 선택한다. 연결 부분 분리는 8방향 연결을 사용하고 미리보기 후 한 번의 Undo 단위로 적용한다. 분리 전후 학습 픽셀이 다르면 적용을 취소한다. AI/채우기 결과는 구멍을 보존하는 잘린 이진 마스크로 저장한다. 모든 편집은 Undo 가능한 단위다. 마스크 렌더링은 확정 결과를 캐시하고 진행 중 획은 변경 구역만 계산한다.

## 저장과 상태

초안은 프로젝트 외부의 사용자 데이터 영역에 이미지 절대 경로 해시로 저장하며 원본 이미지와 라벨의 revision을 확인한다. 복원은 사용자 선택으로 수행한다. 잘못된/오래된 초안은 정답에 적용하지 않는다. 저장 파일은 같은 폴더의 임시 파일을 fsync한 뒤 os.replace한다. 저장 실패 시 완료·다음 이동을 하지 않는다.

기존 작업과의 호환을 위해 사용자의 명시적 정답 저장은 학습용 라벨을 확정하는 동작이다. 자동 초안은 학습에 반영하지 않는다. `검수 완료·다음`은 같은 정답 저장 후 다음 이미지로 이동하며 검수 상태를 추가 기록한다. 검수 여부를 이유로 기존 학습 데이터를 조용히 제외하지 않는다. 이는 계획의 별도 확정 스냅샷 도입에 앞선 호환 가능한 저장 규칙이다.

## 화면과 조작

왼쪽 도구 / 가운데 원본 이미지 / 오른쪽 클래스·객체·이력 / 하단 탐색. 표 전체에 클래스색을 칠하지 않는다. 도구는 태스크별 지원 항목만 노출한다. 화면 맞춤과 실제 1:1, 커서 기준 확대를 구분한다. 객체 다중 선택, 잠금·숨김, 일괄 클래스 변경·삭제·복제, 다각형 점 삽입·삭제, 브러시 영역 선택과 선택 범위 지우기를 지원한다.

작은 박스에는 이름을 겹쳐 표시하지 않고 선택했을 때 읽게 한다. 객체 표에는 앱의 일반 양식보다 작은 패딩을 적용해 클래스·삭제·잠금·표시가 잘리지 않게 한다. 좁은 창에서는 속성 패널을 접고 필요할 때 다시 연다.

8열×16행 격자는 선택한 ROI와 두 축 간격/기준점으로 후보를 만든 후 적용한다. 후보는 확정 전 정답이 아니며 전체 생성은 한 번에 취소한다. 범위 밖 후보는 명확히 표시하고 거부한다.

SAM2는 모델 선택과 로컬 자산을 사용한다. 점/박스 입력 → 제안 → 수동 확인 → 적용이다. 제안은 자동 저장하지 않는다. 오류와 취소 시 수동 편집은 계속 가능하다. SAM2 패키지·자산이 없는 개발 환경에서는 그 이유를 표시하며 다운로드를 시작하지 않는다.

## 검증

기존 세 가지 annotation 테스트를 유지하고 실제 Qt 이벤트로 도구/좌표/Undo/저장/실패 복구를 확인한다. 새 테스트는 잠금·숨김과 학습 픽셀 불변, 선택 지우기, 외부 PNG 선택, 격자 128개, 초안 revision 검사, AI 오래된 응답 폐기를 포함한다. 실제 저장 PNG를 다시 열어 픽셀 비교하며, 가능한 학습 로더도 실행한다.

Windows 설치본·고DPI·대상 CPU 성능은 이 macOS 환경의 결과와 구분해서 기록한다. 확인하지 못한 항목은 완료로 표시하지 않는다.
