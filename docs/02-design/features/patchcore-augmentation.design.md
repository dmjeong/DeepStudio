# PatchCore 증강 및 코어셋 진행 정보 설계

`TrainingConfig.patchcore_augmentation_views`: 0..10, 기본 0. 2이면 이미지당 원본 1개와 증강 2개로 특징을 수집한다. 데이터셋 인덱스와 특징 선택 시드로 별도 난수를 만들어 재현성을 보장하며 전역 RNG를 변경하지 않는다.

공통 원본 전처리 결과를 역정규화한 RGB float에서 좌우 반전, 반사 테두리/선형 보간 회전, 밝기·대비·채도·색조 변화를 적용한 후 동일 정규화를 적용한다. 원본 view는 기존 전처리 경로를 그대로 쓴다. 증강 데이터셋은 정상 라벨만 허용한다. 평가 데이터셋에는 증강 수를 전달하지 않는다.

UI는 PatchCore에서도 세 증강 값을 편집할 수 있게 하고, 적용에는 추가 증강 수가 1 이상이어야 함을 표시한다. 방향 변화가 불량인 경우 반전·회전을 0으로 설정하도록 안내한다. 에폭/학습률/옵티마이저는 계속 비활성화한다.

새 특징 수 = min(max(floor(추출 패치 수 × 비율), 1), 후보 수, 메모리 잔여 용량). 이전 뱅크를 유지하는 추가학습에도 잔여 용량을 적용한다. 요청 수, 실제 수, 제한 사유, 실제 저장 비율, 특징 추출/선별 시간을 메타데이터와 로그에 기록한다.

증강 설정과 실제 이미지/view 수는 워커가 학습 메타데이터에 추가한다. 기존 CSV 생성기의 applied.training_metadata 경로를 사용한다. 버전은 간단 기능 추가 +0.1로 11.60 → 11.70.
