# 설계

- 프로젝트 생성에서는 background(0)를 선예약한다. 명시적으로 첫 항목에 background/배경/bg를 준 기존 호출은 중복 추가하지 않는다. 기존 저장 프로젝트의 ID는 load에서 임의 변경하지 않는다.
- 빈 기존 프로젝트에서 ClassManager.add도 같은 예약 규칙을 사용한다. 클래스 상한(0..254, ignore 255)을 공통 검증한다.
- 잘못된 ID 0 이름 복구는 별도 트랜잭션: 기존 1 이상 ID는 보존하고 첫 이름은 새 전경 ID에 추가, 0 이름은 background로 고친다. 원본 백업과 실패 롤백을 유지한다. 배경 픽셀을 결함으로 일괄 치환하지 않는다.
- semantic 학습 쌍은 mask=None을 자동 배경으로 표현한다. indexed 파일 중복/고아 마스크 검증은 유지한다. 마스크가 있으면 원본 크기·모드·ID를 검증한 뒤 축소한다. 폴리곤만 존재하면 배경으로 오인하지 않고 설명 가능한 오류를 낸다.
- 중앙 crop는 누락 마스크를 그대로 누락으로 유지하여 같은 정책을 적용한다. 손상 라벨은 crop 전에 검증한다.
- SAM2는 배경의 유효 픽셀에 음성 point(label=0)와 빈 target을 사용한다. foreground point(label=1)는 유지한다. ignore=255는 target에서 보존하고 ignore-only 이미지는 제외한다. 배경-only val도 검증 가능하다.
- UI 미라벨 표시는 '자동 배경'을 명시하고 학습 로그에 train/val 개수를 기록한다. 기본 배경을 직접 그리도록 유도하지 않는다.
- 테스트는 계약 단위 + 실제 Qt 입력 + 생성 데이터의 소형 모델 학습 + 공식 SAM2 CPU 스모크로 구성한다. classification/미완성 B1 실험은 이번 배포에 포함하지 않는다.
