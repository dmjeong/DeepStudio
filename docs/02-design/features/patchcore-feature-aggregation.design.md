# PatchCore 특징 집계 수정 계획·설계 (2026-11-10)

## 문제와 확인 근거

사용자는 이미 고정 224×224 격자 패치로 학습 중이며, 백본을 바꿔도 정상·불량 점수가 겹친다고 보고했다. 전체 영상 축소로 원인을 단정한 앞선 설명을 철회한다.

현재 `PatchCoreBackbone`은 layer3를 layer2 크기로 확대한 뒤 결합하고, `PatchCore`가 3×3 평균을 낸다. Anomalib은 각 layer의 원래 공간 격자에서 3×3 평균을 낸 뒤 확대·결합한다. 두 연산 순서는 동등하지 않으며 특히 낮은 해상도 지도에서 집계하는 원본 영역이 다르다.

로컬 탐색 실험 `runs/patchcore-grid-quality-20261110/experiment.py`는 RGB 합성 트레이를 224 stride의 격자로 나누고 부분 경계는 반사 패딩했다. 정상 4장, val 2장+정상 보정 2장, 시험 10장, 공식 사전학습 ResNet18, 저장 특징 1,024개, seed 0이다. 불량 픽셀이 조금이라도 포함된 타일을 양성으로 보았다. 이전 실험의 데이터를 재사용한 탐색 비교이며 생산 검출률의 독립 검증이 아니다.

- 기존 layer2/3: 검증 F1 기준으로 시험 불량 패치 12/33 검출, 정상 8/1,087 오검출.
- layer별 평균 후 결합: 23/33 검출, 정상 0/1,087 오검출.
- 같은 집계에 layer1/2 사용: 15/33 검출, 정상 3/1,087 오검출. 채택하지 않는다.
- 미검출 10개가 남았다. 이 수정으로 사용자 문제 전체가 해결된다고 주장하지 않는다.

## 변경 계약

1. `feature_aggregation`을 명시한다: `align_then_pool_v1`(기존), `pool_then_align_v2`(신규).
2. 신규 모델은 v2. 기존 체크포인트 schema 1..5는 v1로 복원한다. 새 체크포인트 schema 6은 집계 필드를 필수로 두어, 옛 앱이 무시하고 잘못 읽지 못하게 한다.
3. 기존 체크포인트를 추론하거나 추가 학습할 때는 기존 집계·점수 방식을 보존한다. 기존 백본으로 **새 뱅크 구축**할 때만 v2 집계·현재 점수 방식을 적용한다. 저장된 정상 특징을 새로운 특징 공간에 섞지 않는다.
4. 신규 v2는 백본 안에서 각 레이어에 평균 풀링을 적용하고 외부 풀링은 Identity다. 기존 v1은 기존 코드 경로를 그대로 사용한다. 레이어·가중치·특징 차원·출력 텐서 형식은 유지한다.
5. ONNX는 선택한 집계 연산을 그래프에 포함한다. 배포 JSON에는 집계 식별자를 참고 정보로 기록한다. C++ 입력·출력 계약은 동일하다.
6. 학습 로그·체크포인트·학습 메타데이터로 실제 집계 방식을 확인할 수 있게 한다.

## 검증·완료 조건

- 고정된 특징 텐서로 두 연산 순서의 비동등성과 새 집계의 기대 출력을 검사한다.
- 구버전 체크포인트 복원 후 원시 점수·지도·임계값이 그대로인지 확인한다.
- 새 체크포인트 저장/복원, 필드 누락·알 수 없는 집계 거부, 추가 학습/새 뱅크 구축 정책을 검사한다.
- 실제 Torch 모델 → ONNX → Python ORT → C++ 점수·지도·판정 회귀를 두 집계 방식 모두에서 실행한다.
- 합성 사전학습 실험과 제품 구현의 출력을 대조한다. 임계값을 시험 결과에 맞춰 재설정하지 않는다.
- 기능 검증과 검출 정확도를 별도로 보고한다. Windows 및 사용자 비공개 데이터는 미검증으로 표시한다.

## 추가로 재현한 배포 경계 문제

사전학습 모델을 내보내 검증하는 중, val의 경계 샘플에서 F1 임계값과 점수가 같아 PyTorch/ORT의 미세 차이로 판정이 달라졌다. 검증셋만 사용하여 선택된 F1 구분을 유지하는 인접 점수 사이 FP32 중간값으로 보정한다. 표현 가능한 간격이 없으면 기존값과 margin=0을 기록한다. 기존 체크포인트의 임계값은 로드 시 변경하지 않는다.

같은 중간값 정책을 세 탐색 후보에 적용한 시험 결과: 기존 집계 15/33, FP 9/1,087; 수정 집계 23/33, FP 0/1,087; layer1/2 15/33, FP 3/1,087. 중간값은 같은 검증 판정을 유지하지만 새 시험 입력은 기준 사이에 들어갈 수 있어, 처음 보고한 기존 후보의 12/33과는 다르다.

제품 구현의 336패치 점수는 연구 구현과 정확히 일치. 공식 사전학습 모델 14패치의 PyTorch→ORT→C++ 판정은 수정된 기준에서 일치했다. 기록: `runs/patchcore-grid-quality-20261110/product-verification.json`.
