# Modern dense models — 구현 계약

사용자 요청: 최신 분할/이상검출과 증류를 실제 앱에 추가하고 FP32·INT8 ONNX, C++ 사용, 원본 비교, 지원 가능한 증강·패치 학습까지 완성한다.

## 범위

- EfficientViT B0/B1 segmentation: 공식 다중 해상도 합산·MBConv 헤드, ImageNet 백본.
- SCTNet-S: 공식 CNN/CFBlock/DAPPM 구조, 분할 보조 손실, 선택적 교사 증류.
- EoMT DINOv2-S: 후반 ViT 블록에 마스크 쿼리 삽입, 마스크·클래스 예측. DINOv2 가중치 공유.
- Dinomaly DINOv2-S: 정상 이미지로 고정 인코더와 잡음 병목·선형 어텐션 재구성기를 학습. PatchCore 메모리 뱅크와 구분.
- 분할 교사 체크포인트 → 동일 증강 입력의 픽셀 증류. 클래스 순서·전처리·파일 해시 검사, 재개 설정 보존.
- SegMAN은 CUDA selective-scan/NATTEN 의존 때문에 이번 CPU 기본 모델 대상에서 제외한다. 지원하지 않는 모델을 완료로 등록하지 않는다.

## 배포·UI

- 기존 전처리/타일/정답/배경0/제외255/원본 비교 계약 재사용. 전역 특징 모델은 학습 크기 타일 추론.
- FP32 원본 대비 ONNX 검증. INT8은 실제 보정 이미지와 동일 전처리를 사용하고 차이 리포트 기록; 정확도 불변을 보장하지 않는다.
- INT8 경로는 whole-image CNN과 고정 타일 Transformer를 모두 처리. FP32·INT8 각각 C++ 출력 대조.
- 사전학습은 build-time 준비, 실행/복원/export에서 몰래 다운로드하지 않는다. 코드·가중치 라이선스/출처 분리 기록.
- 체크포인트와 CSV에 실제 설정을 저장. 모델별 학습시간/지표 갱신, 취소, best/재개, 로컬 가중치 지원.

## 검증

모델별 실제 forward/backward/저장/복원, 증강·패치 적용, FP32/INT8 ORT CPU, C++ 로드와 출력/원본 좌표 비교, Qt 선택/학습 설정/원본 비교를 검사한다. 작은 인공 데이터의 연결 검사는 실제 검사 정확도 증거가 아니다. Windows 실행 및 사용자 데이터 성능은 별도 범위로 명시한다.
