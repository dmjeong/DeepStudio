# 14.88 — SEG 합성 중복 입력 허용

사용자 지시: 중복 이미지가 있어도 분석/생성을 진행한다.

- 같은 분할 및 Train/Val/Test 사이의 동일 픽셀 이미지를 차단하거나 자동 삭제하지 않는다.
- 각 파일을 자기 분할/정답과 함께 개별 보존한다. 같은 영상의 서로 다른 정답도 임의로 합치지 않는다.
- 첫 동일 이미지의 ID를 출처에 기록하고 분석 상세에 중복 입력 수를 표시한다. 확인/승인 절차를 추가하지 않는다.
- Train 참조→Train 바탕, Val 참조→Val 바탕의 생성 구분은 유지한다. Test는 참조로 쓰지 않는다.
- 검증: 중복 입력의 실제 분석·생성·승인·새 프로젝트 저장, 상이한 정답 및 경로 보존, 실제 GUI 버튼 클릭.
