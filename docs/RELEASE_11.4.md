# Deep Vision Studio 11.4

Dataset 화면의 클래스 필터가 Train, Val, Test 전환에 따라 달라지는 문제를 수정합니다.

- 어느 분할에서 클래스를 선택하든 모든 분할에 같은 필터 적용
- 해당 클래스 이미지가 없는 분할에서도 선택을 유지하고 0장 표시
- 상단 대상 콤보로 분할을 바꾸어도 공통 필터 유지
- 같은 프로젝트의 클래스 목록 갱신 시 선택 유지. 선택 클래스 삭제 또는 다른 프로젝트 진입 시 전체로 초기화
- 클래스 필터 변경 시 이전 이미지 선택 해제로 숨겨진 이미지의 일괄 작업 방지
- 데스크톱의 실제 이미지 필터링과 React 브라우저의 empty 클래스 분할 전환 검증

React는 기존 실행용 ZIP으로 배포합니다.
