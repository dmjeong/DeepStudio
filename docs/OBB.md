# 회전 박스 데이터 편집

OBB 태스크에서는 이미지의 회전 박스 주석 작성, 클래스 변경, 이동과 크롭을 지원합니다.
학습·모델 추론·ONNX 내보내기 엔진은 제공하지 않습니다.

라벨 한 줄은 `class x1 y1 x2 y2 x3 y3 x4 y4`이며 좌표는 이미지 크기에 대해
0~1로 정규화합니다. 네 꼭짓점은 교차하지 않는 둘레 순서여야 합니다. 세 점으로
직사각형을 그릴 때에는 실제 이미지 픽셀 비율을 사용합니다.

크롭은 좌표를 새 원점과 크기에 맞춰 이동합니다. 크롭 경계에 걸쳐 일부만 남는
회전 박스를 임의로 축소하거나 각도를 바꾸지 않고 오류로 알립니다.
데이터 편집 결과와 클래스 재번호화는 저장 전 검증하며 실패 시 이전 상태를 복원합니다.
