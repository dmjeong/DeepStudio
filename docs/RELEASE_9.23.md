# 9.23 — 공통 라벨링 작업실

신규 기능 릴리스이므로 사용자 버전 규칙에 따라 8.23에서 +1.0으로 올렸다. 이 문서는 로컬 개발·검증 기록이며 Windows 설치본의 실기기 승인 기록은 아니다.

## 구현

Detection과 Segmentation에 공통 작업창, 사용자 클래스·객체·이력 패널, 다중 편집, 잠금·숨김, 실제 픽셀 기준 확대, 변경 가능한 단축키를 연결했다. 브러시/기존 PNG 영역 선택, 범위 제한 지우기, 원형·사각 브러시, 다각형 점 편집·스냅, 채우기 제안, 화면 전용 밝기·대비를 제공한다.

격자는 8×16 기본값, 이미지에서 찍는 기준점, 3점 아핀/4점 원근 보정, 제외할 칸 선택과 전체 Undo를 지원한다. SAM2는 기존 번들 자산으로 실행하며 점·박스 제안, 취소와 오래된 응답 차단을 포함한다.

초안은 정답과 분리한다. 명시적 저장은 학습 정답 확정이며 창을 유지한다. 정답 변경 감지, 저장 revision 검사, 원자 저장, 중단 복구 저널을 추가했다. 메타데이터 v1을 읽고 v2의 구멍·255 무시 영역·래스터 영역을 표준 PNG 픽셀로 보존한다. 새 형식의 웹 덮어쓰기는 막는다.

## 검증 기록

최종 테스트·성능 결과는 [구현 검토 기록](03-analysis/annotation-workspace.analysis.md)에 기록한다. 실행 명령은 [사용법](ANNOTATION_WORKSPACE.ko.md)에 있다.

관련 회귀 174개, Qt 125/150/200% 각 10개, 웹 단위 테스트 14개와 웹 빌드가 통과했다. 실제 SAM2.1 Tiny CPU 제안의 적용·저장·재열기 픽셀이 일치했다. 합성 4096²/128개 객체의 편집 반응 p95는 1.81ms, 1,000개 스트레스는 1.98ms였다. 500회 창 열기·닫기에서 문서 객체 보존은 없었고 Qt 아이콘 캐시가 찬 뒤 메모리는 수렴했다.

로컬 플랫폼은 macOS arm64, Python 3.12, PySide6 6.12다. 실제 Windows 결과와 구분해서 해석해야 한다.

Windows 네이티브 설치본, Windows 고DPI/다중 모니터 이동, 목표 i7의 반응 시간과 SAM2 GPU 실행은 이 환경에서 직접 확인하지 않았다. 편집 반응 속도 측정값을 모델 추론 시간으로 해석하면 안 된다.

## 호환 범위

기존 데이터의 파일 형식은 TXT와 클래스 번호 PNG다. 클래스를 저장 순서·화면 정렬로 다시 번호 매기지 않는다. 숨김은 학습 픽셀을 바꾸지 않는다. 구버전 편집기에서 새 편집 정보를 잃을 수 있으므로 새 마스크는 지원되는 데스크톱 작업실에서 수정한다.

학습 중 편집은 기존 idle 가드로 제한한다. 별도의 모든 이미지/라벨 복사본을 만드는 학습 스냅샷 기능은 도입하지 않았다. 자동 초안이 학습에 반영되지 않고 명시적 저장만 정답을 바꾸도록 저장 규칙을 확정했다.
