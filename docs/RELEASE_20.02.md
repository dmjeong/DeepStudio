# Deep Vision Studio 20.02

객체 탐지의 **mAP50**은 정답 박스와의 IoU 0.50에서, **mAP50–95**는 IoU 0.50부터 0.95까지 여러 기준에서 검출 순위의 품질을 평가합니다. 작은 박스는 몇 픽셀만 어긋나도 높은 IoU를 얻기 어렵습니다. [COCO 평가 기준](https://cocodataset.org/#detection-eval).

새 학습의 **Precision·Recall**은 점수 0.25 및 IoU 0.50에서 같은 클래스의 예측과 정답을 하나씩 맞춰 계산합니다. 검증 정답이 없는 클래스의 Recall은 평가할 수 없고, 그 클래스로 잘못 예측한 박스는 전체 오검출에 반영됩니다. 클래스별 정답 수와 검출·오검출·놓침을 확인할 수 있습니다.

학습 탭에는 Best 체크포인트의 에폭과 지표가 표시됩니다. 학습 이미지로 검증을 대신하지 않으므로, 별도의 Val 이미지와 정답 박스가 필요합니다. 패치 학습의 검증 mAP는 검증 패치에서 계산하므로 원본 한 장으로 묶어서 낸 판정과 비교할 때 평가 단위가 다릅니다.

이전 LibreYOLO·Re-DETR·D-FINE 학습 기록에는 고정 점수 Precision·Recall이 저장되어 있지 않습니다. 기존 mAP를 확인할 수 있으며, 새 기준의 Precision·Recall은 새 학습에서 기록됩니다.
