# 0.0: 새 기준 버전

Deep Vision Studio의 버전을 `0.0`부터 다시 관리한다.

- 버그 수정 릴리스는 `+0.01`을 적용한다.
- 간단한 기능 추가 릴리스는 `+0.1`을 적용한다.
- 신규 기능 또는 모델 추가 릴리스는 `+1.0`을 적용한다.

이번 기준 버전에는 Windows EXE 빌더가 같은 Python 환경에 GUI 의존성을 설치하고 PySide6·Qt 런타임을 명시적으로 수집하는 수정이 포함된다. 따라서 PySide6가 빠진 EXE가 만들어진 뒤 시작 시 `Failed to execute main`으로 종료되는 경우를 빌드 단계에서 막는다.
