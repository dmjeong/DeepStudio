# 23.02 — CSeVision 초기화·교체 두 함수 (+0.1)

[사용 코드와 CSV](../example/cpp/with_evision/FILENAME_CSV_MODELS.md)

`sevision_csv_example.h`에 `InitializeModel()`과 `ChangeModel()`만 제공한다.
별도 감시 스레드를 만들지 않고 사용자의 스레드에서 주기적으로 확인한다.
기존 `shared_ptr`를 index별로 보관하고, 추론은 `atomic_load`로 받는다.

초기화는 모든 모델을 준비한 후 공개한다. 모델 변경은 새 파일만 한 번 복호화하고
워밍업한 뒤 교체하며, 실패한 모델은 기존 포인터를 유지하고 다음 호출에서 재시도한다.
이전 사용자가 끝난 모델은 교체 함수가 해제한다. 기존 자동 감시 API는 유지한다.

회귀 검사에는 사용자 스레드 방식에서 자동 로드가 없는지, 변경 없는 호출에 키/모델을
다시 읽지 않는지, 초기화 실패 시 부분 공개하지 않는지, 병렬 추론 중 포인터 교체,
잘못된 키·모델/파일 누락의 복구와 이전 모델 회수를 포함한다.

로컬 C++17·ONNX Runtime 1.22.0 검사 9개, 버전 정책·설치본 포함 검사 35개 통과.
새 두 함수 예제와 회귀 코드는 Clang `-Wall -Wextra -Werror` 검사도 통과했다.

BW8 분류용이다. 실행 중 CSV index 구조/카메라 매핑 변경은 거부하고 다음 시작 시 적용한다.
실제 VS2017/eVision 실행과 대상 장비의 교체 중 성능은 로컬 macOS 검증과 구분한다.
