# Deep Vision Studio 11.3

Data Gen을 실제 불량 데이터 학습 흐름으로 개편한 기능 릴리스입니다.

## 추가 수정

- 그룹명 앞뒤 공백을 정규화하여 Train/Val 경계 우회 차단
- 두 UI가 공유하는 GPU 작업 잠금과 프로젝트 변경 잠금 적용
- 학습 중 다른 UI의 데이터 변경 차단과 작업 종료 후 재개 검증

## 변경

- 사용자가 학습 항목 추가, 이름 변경, 검사 클래스 연결 및 보관 가능
- 실제 이미지와 검수 마스크, 그룹별 Train/Val 분리 및 불변 학습 버전
- 9채널 SD/SDXL Inpainting UNet LoRA 학습과 별도 프로세스 생성
- 실제 Val Loss 최소 Best, 품질 검수 Best, 이어학습 Last 분리
- 원본 좌표 마스크 편집, 국소 생성, 원본/결과 비교 및 영구 검수
- 승인한 이미지와 별도 불량 정답 마스크만 새 train 버전으로 저장
- 선택 설치하는 전용 Data Gen 환경. 모델 가중치는 배포에 미포함

## 검증과 제한

CI에서 회귀 테스트, UI 통합, 데이터 무결성과 소형 Diffusers의 실제 LoRA 역전파 및 재로드를 검사합니다.
실제 사전학습 모델의 GPU 학습, 생성 품질과 검사 미검/과검 개선은 사용자 장비와 실제 데이터로 검증해야 합니다.
이번 배포는 이를 위한 실험 기능 코드이며 GPU 품질 검증 완료 릴리스로 표시하지 않습니다.
AI 생성은 8비트 RGB/흑백에 한정합니다. 16비트 높이 데이터는 기존 규칙 도구를 유지합니다.
정상 데이터를 임의 노이즈로 합성한 결과를 AI 학습 결과로 대체하지 않습니다.

설치와 작업 절차: [DATA_GEN.md](DATA_GEN.md)

React는 기존 실행용 ZIP과 SHA-256, 시작 배치 파일을 제공합니다.
