# Desktop 14.9: 추론 입력 영역 선택

- 추론 화면에서 모델 설정 사용, JSON 설정 사용, 원본 전체 사용을 선택합니다.
- JSON에서 읽은 중앙 크기와 최종 모델 입력 크기를 표시합니다.
- 분류, 검출, 세그멘테이션, PatchCore, 재구성 이상 탐지에 적용합니다.
- JSON은 작업 시작 시 고정하고 사용한 영역과 JSON SHA-256을 결과에 기록합니다.
- 모델 파일의 학습 설정을 보존하며 박스, 마스크와 히트맵을 실제 입력 영역에 맞춰 복원합니다.
- 작은 모델 입력 패널과 우측 배치 결과 표를 유지합니다.

사용법과 JSON 예시는 [추론 입력 영역](INFERENCE_REGION.md)을 참고해 주세요.

검증 범위: JSON 호환성과 오류 처리, 실제 Custom 네 태스크와 공식 분류 CPU 입력 비교, 16비트 PatchCore 입력과 히트맵, Qt 별도 프로세스의 세 가지 모드 전환과 배치 결과 레이아웃. Windows/Linux CI 통과 후 태그와 소스 ZIP을 게시합니다. 현장 데이터 정확도와 GPU 성능은 별도 검증 대상입니다.

배포 첨부는 소스 ZIP 한 개이며 EXE는 첨부하지 않습니다.
