# Desktop 15.9: 데이터셋 원본 확대와 태스크별 추론 결과

- 데이터셋 격자의 썸네일을 더블 클릭하면 원본 이미지 확대 화면을 엽니다.
- 데이터셋과 추론 격자에 세로와 가로 스크롤바를 제공합니다.
- 격자 썸네일은 고정 크기로 표시하며 확대와 이동은 단일 이미지 화면에서만 제공합니다.
- 추론 상세 영역을 태스크별로 구성해 분류 전체 확률, 검출 목록, 세그멘테이션 픽셀 분포, 이상 점수와 판정을 표시합니다.
- 분류 확률은 상위 일부만 자르지 않고 모델이 반환한 모든 클래스를 표시합니다.

사용법과 입력 영역 JSON 규약은 [추론 입력 영역](INFERENCE_REGION.md)을 참고해 주세요.

검증 범위: 데이터셋 확대 대화상자, 양방향 격자 스크롤, 태스크별 결과 상세, 분류 전체 확률 표시와 기존 추론 영역 회귀 검사. GPU 성능과 현장 데이터 정확도는 별도 검증 대상입니다.

배포 첨부는 소스 ZIP 한 개이며 EXE는 첨부하지 않습니다.
