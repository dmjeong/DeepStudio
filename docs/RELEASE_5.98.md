# Deep Vision Studio 5.98

ONNX 내보내기의 `실제 이미지 추가 검증`은 모델 정답률을 측정하지 않는다. 같은 이미지를 PyTorch와 ONNX Runtime에 넣었을 때 top-1 판정과 확률이 일치하는지 검사한다. 따라서 폴더명은 정답 라벨이 아니며, 이미지가 직접 들어 있는 평면 폴더도 사용할 수 있다.

클래스별 하위 폴더를 선택한 경우에도 전체 데이터가 0장인 클래스는 오류로 처리하지 않고 실제 이미지 검증 범위에서 제외한다. 검증 JSON에는 클래스별 이미지 수, 비표시 클래스, 라벨 없는 이미지 수를 기록한다. 비표시 클래스의 정확도를 검증했다고 해석하면 안 된다.

기본 `출력 검증` 자체는 결정론적 합성 입력으로 동작하며 폴더가 필요 없다. 폴더는 `실제 이미지 추가 검증`을 켰을 때만 필요하다.
