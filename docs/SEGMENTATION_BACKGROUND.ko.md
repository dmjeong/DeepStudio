# 세그멘테이션 클래스와 자동 배경 학습 (9.44)

## 새 프로젝트

클래스 입력에는 `scratch, dent`처럼 검사할 영역 이름을 적습니다. 프로그램이 `background`를 0번으로 예약하고 `scratch=1`, `dent=2`로 등록합니다. 배경을 직접 그릴 필요는 없습니다. `background, scratch`처럼 배경을 이미 맨 앞에 적었다면 중복 등록하지 않습니다. 기존 관례인 `bg`, `배경`, `good`, `normal`, `정상`도 첫 항목에서는 배경으로 인식합니다.

이미지 전체가 아니라 **그린 영역에 클래스가 지정됩니다**. 배경 항목은 그리기·재분류 대상에서 비활성화되고, 첫 결함 클래스가 기본 선택됩니다. 지우기는 지우개/선택 삭제를 사용합니다.

## 기존 프로젝트의 첫 클래스가 그려지지 않을 때

Dataset의 통계·필터에는 첫 이름을 포함한 모든 등록 클래스가 표시됩니다. 구형 프로젝트에서
0번에 결함 이름이 저장되어 있으면 해당 행에 **복구 필요**와 상단 안내가 표시됩니다.
이때 **첫 클래스 복구**를 누릅니다. 화면을 여는 것만으로 원본 정답을 변경하지 않습니다.

- 0번은 배경으로 바꾸고, 기존 첫 이름을 새 전경 번호로 추가합니다.
- 기존 1번 이상 클래스 번호와 과거 학습 기록은 유지합니다.
- 마스크에 남은 편집 이력 또는 폴리곤에서 0번으로 그렸던 영역을 새 전경 번호로 복구합니다.
- 원본 마스크와 프로젝트는 `.deep_studio_dataset_archive`에 백업합니다. 저장 실패 시 원상 복구합니다.
- 편집 이력이 없는 평면 마스크의 0번 픽셀은 배경과 결함을 구별할 정보가 없습니다. 그 부분은 배경으로 유지되므로 필요한 결함을 다시 표시해야 합니다.

## 라벨 없는 이미지

배경 클래스 행의 `배경 · N장`은 배경 픽셀이 있는 이미지와 라벨 없는 자동 배경 이미지 수입니다.
전경과 배경이 함께 있는 이미지도 포함됩니다. 아래의 `배경만` 행은 정답 파일이 있고 전경 영역이 없는
이미지 수, `자동 배경 (미라벨)` 행은 정답 파일이 없는 이미지 수로, 서로 더하는 통계가 아닙니다.

U-Net, DeepLab V3+, 커스텀 시맨틱 분할, SAM2의 학습·검증에서 **마스크 없는 이미지는 자동으로 배경 정답(ID 0)** 으로 포함됩니다. 정상 이미지는 따로 라벨 파일을 만들거나 '배경만 있음 확인'을 누를 필요가 없습니다. 중앙 크롭을 사용해도 같은 규칙입니다.

데이터 화면의 `자동 배경`과 학습 로그에서 적용 개수를 확인할 수 있습니다. 원본 폴더에 가짜 마스크를 생성하지 않습니다. 결함이 있는 이미지에는 결함 영역을 표시해야 합니다.

이미 존재하는 마스크가 손상됐거나 이미지와 크기가 다르거나 클래스 번호가 잘못됐으면 오류를 표시합니다. 이것을 배경으로 바꾸지 않습니다. 255번은 배경이 아닌 **학습 제외**입니다. 폴리곤 TXT만 있고 픽셀 마스크가 없으면 라벨링 화면에서 열어 저장해 마스크를 생성합니다.

SAM2는 배경 이미지에 음성 프롬프트와 빈 정답을 사용하고, 255 픽셀은 손실에서 제외합니다. 학습한 단일 마스크 출력을 검증·재로드·ONNX 내보내기에서도 사용합니다. SAM2가 일반 다중 클래스 시맨틱 모델로 바뀌는 것은 아니며, 기존 프롬프트 기반 모델 계약을 유지합니다.

## 확인 범위

생성 이미지로 U-Net ResNet18, DeepLab V3+ ResNet34, 공식 SAM2.1 Hiera Tiny의 실제 CPU 학습과 ONNX 출력 검증을 실행했습니다. SAM2는 미라벨 배경을 포함한 학습, 배경만 있는 검증셋, 체크포인트 재로드도 확인했습니다. 이는 기능 연결 검사이며 실제 검사 데이터의 정확도 측정이 아닙니다. Windows/CUDA와 나머지 SAM2 크기의 실제 실행은 이 환경에서 수행하지 않았습니다.
