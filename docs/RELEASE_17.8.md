# React 17.8: CustomCSP OBB 회전 객체 탐지

- 독립 OBB 프로젝트와 CustomCSP n/s/m/l/x 모델 선택을 추가합니다.
- 네 꼭짓점 라벨 검증, 클래스 추가와 변경, 분할 이동을 지원합니다.
- 데이터셋에서 세 번 클릭으로 회전 박스를 그리고 클래스 수정과 삭제 후 저장합니다.
- 공식 OBB 학습, Best 체크포인트, loss와 회전 mAP, CPU 추론을 연결합니다.
- 중앙 크롭 라벨 변환과 추론의 전체 이미지 좌표 복원을 적용합니다.
- 추론 결과에 회전 박스, 클래스, 신뢰도, 긴 변 기준 각도와 크기를 표시합니다.
- ONNX 검증에 OBB 출력을 포함하고 배포 JSON에 전처리와 OBB 후처리 정보를 기록합니다.

사용법과 제한은 [OBB 안내](OBB.md)를 참고하세요. 객체 일부를 자르는 학습 크롭은 거부하며 OBB는 공식 폐기된 외부 엔진 엔진을 사용합니다. 기존 C++ 런타임에서 OBB를 지원한다고 표시하지 않습니다.

검증: 라벨 무결성과 저장 실패 복구, 비정사각형 이미지 좌표, CPU 학습과 저장 후 재로드, ONNX 내보내기, Qt 편집 회귀 검사를 포함합니다. React는 실제 배포 ZIP의 브라우저 편집과 저장 후 재확인도 검사합니다. 필수 CI가 통과해야 릴리스가 생성됩니다. 현장 데이터 정확도와 GPU 성능 검증은 별도입니다.
