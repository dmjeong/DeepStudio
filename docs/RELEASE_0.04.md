# 0.04: EfficientNet ONNX 검증 실패 시 원본 그래프 재시도

EfficientNet ONNX 내보내기는 사전 융합한 그래프의 검증 실패 시 즉시 종료했지만, 앱 내부 ONNX 추론에는 원본 그래프 재시도가 있었다. 내보내기에도 원본 FP32 그래프로 재시도하는 경로를 추가했다.

재시도는 Conv/BN 사전 융합, 상수 폴딩 및 선택적 단순화를 제외하고 수행한다. ONNX Runtime 기본 설정에서 원본 PyTorch와 동일한 수치 오차 및 top-1 검사를 통과해야 저장한다. 랜덤·영 입력 및 요청한 동적 배치를 검사하며 두 경로 모두 실패하면 각각의 오류를 표시하고 기존 배포 파일을 보존한다. 허용 오차는 변경하지 않았다.

B0 1채널 224×224 실제 ONNX로 재시도 성공 및 실패 파일 보존을 검사했다. 첫 최적화 실패는 테스트에서 주입했다. 사용자 가중치에서 보고된 최대 오차 27.9941을 재현하거나 해결을 확인한 것은 아니다.
