# 7.18 — 추론 배치결과 클래스·판정 필터 수정

## 원인과 변경

판정 선택지는 OK/NG 등 고정값이었지만 분류 행의 판정은 클래스 이름과 확률을 합친 문자열이었다. 따라서 사용자 클래스 이름으로 분류 결과를 고를 수 없었다. 클래스 선택지도 현재 행의 데이터셋 폴더만 사용해 모델·프로젝트의 전체 클래스 목록을 반영하지 않았다.

프로젝트·모델의 클래스 목록과 실제 결과로 필터를 구성한다. 분류 판정은 저장된 `class_names`와 `probabilities`의 최대 확률 인덱스로 결정한다. 데이터셋 클래스는 정답, 판정은 모델 예측이라는 구분을 유지하며 외부 이미지에 정답을 만들어 넣지 않는다. 원본 결과와 확률은 변경하지 않는다.

Qt와 웹에 같은 공통 규칙을 적용하고, 모델 변경이나 임계값 조정으로 선택지가 없어지면 실제 필터 조건도 해제한다.

## 확인 범위

- 사용자 클래스명(한글·공백·숫자·% 포함), 서로 다른 확률의 동일 클래스, 정답과 예측의 조합 필터
- 미사용 클래스, 오류·대기 상태, 이상탐지 임계값 변경, 모델 전환 시 이전 필터 해제
- Qt 배치결과 위젯과 웹 결과 페이지의 공통 계산 및 웹 빌드

검증 결과: 관련 Python·Qt·웹 API·비동기 추론·버전 테스트 19개 통과, `npm run build` 통과, `git diff --check` 통과. macOS 로컬 환경에서 확인했으며 Windows 설치본 실행은 이번 검증에 포함하지 않았다.
