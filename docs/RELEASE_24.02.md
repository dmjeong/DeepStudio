# 24.02 — CrackSegNet Studio 추가 (+1.0)

- 분할 학습 화면에 `CrackSegNet Studio`를 추가했다. 2026년 Yu·Mei·Zhu 논문을 참고한
  자체 구현이며 공식 모델의 완전한 재현이 아니다. 사전학습 가중치를 제공한다고 표시하지 않는다.
- 변형 합성곱, 픽셀 재배열 인코더/디코더, 지역 그래프 주의를 사용한다. 배경 포함 다중 클래스,
  RGB/BW8, 증강·패치·원본 크기 학습, 재개·전이·기존 증류 경로에 연결했다.
- FP32, 좌표 연산 FP32를 보존한 FP16, 보정 데이터 기반 QDQ INT8, 암호화 배포를 지원한다.
  opset 16 미만은 설명과 함께 거부한다. 기본값은 17이다.
- scratch 모델의 중단한 학습 재개 항목과 설치본 모듈 포함을 추가했다.

구조·차이점·사용 방법·검증 한계는 [CrackSegNet Studio 안내](CRACKSEGNET_STUDIO.md)에 기록했다.
실제 검사 데이터의 검출률과 Windows i7 속도는 사용자 데이터/장비에서 별도로 비교해야 한다.

검증 결과: 모델·레지스트리·FP16 변환·원본 학습·설치 목록·버전 관련 검사 108개 통과,
CUDA 장치가 필요한 검사 2개 제외. 마지막 원본 비교/추론 연결 검사까지 새 모델 검사
11개 통과, CUDA 검사 1개 제외. 합성 RGB 크랙·이물질을 40에폭 학습해 두 전경 클래스가
검출되는지 확인했다. 이는 수렴·연동 검사이며 실제 검사 정확도 평가가 아니다.

C++17 Clang으로 별도 ONNX Runtime 1.22.0에 연결한 검사 프로그램을 빌드하고,
FP32·FP16·INT8 각각에서 Python 출력과 비교했다. 각 정밀도 내 일반/암호화 모델의
출력은 동일했다. Windows VS2017/eVision 및 CUDA GPU의 실제 실행은 이 로컬 검사에
포함되지 않는다. OpenCV를 통한 전체 분할 SDK 경로도 CI 검사에 연결했다.
