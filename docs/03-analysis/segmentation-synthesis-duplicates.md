# 14.88 검증 — SEG 합성 중복 입력 허용

## 원인과 변경

`SynthesisStore._analyze`는 픽셀 해시가 같은 이미지를 발견하면 서로 다른 분할은 오류로 중단했고, 같은 분할은 정답이 다르면 중단하고 같으면 제외했다. 사용자 요청에 따라 이 차단/제외를 제거했다.

모든 입력 파일을 별도 ID로 저장하고 파일마다 원래 분할과 정답을 유지한다. 동일 픽셀의 첫 입력 ID와 중복 수는 출처 확인용으로만 기록한다. 생성과 프로젝트 저장은 보존된 전체 입력을 사용한다. 별도의 승인이나 중복 허용 체크는 없다.

## 확인한 동작

- 같은 분할의 동일 이미지·동일 정답을 모두 보존한다.
- 같은 이미지에 다른 정답이 있는 경우에도 각 정답을 보존한다. 하위 폴더의 동일 파일명도 검사했다.
- Train/Val/Test에 같은 이미지가 있어도 분석·생성을 완료한다.
- 중복 원본 8장과 승인 합성본 1장을 새 프로젝트에 저장한 뒤 원본별 정답 픽셀을 대조했다. Train 5장, Val 2장, Test 2장을 확인했다.
- 실제 Qt 분석 버튼과 미리 생성 버튼을 눌러 클래스 5종의 참조 표시 및 후보 생성을 확인했다. 중복 확인/오류 창은 표시되지 않았다.
- Test를 참조로 쓰지 않는 동작과 Val 후보를 학습용으로 게시하지 않는 동작은 유지된다.
- 잘못된 클래스 마스크, 참조 없는 데이터, 취소/잠금 경합, 기존 학습·ONNX 경로의 회귀 검사를 포함했다.
