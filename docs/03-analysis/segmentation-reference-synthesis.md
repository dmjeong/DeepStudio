# SEG 정답 기반 가상 불량 — 14.86 검증 보고서

## 구현 범위

설계: [segmentation-reference-synthesis.design.md](../02-design/features/segmentation-reference-synthesis.design.md).

- 실제 Train/Val의 마스크·폴리곤을 읽고 원본 크기의 참조, 배경, 클래스 정답을 고정했다.
- crack/FM은 결함 질감·윤곽을, shift/double/flip은 주변 배치까지 보존하는 합성을 구현했다.
- 참조 없는 클래스, 맞는 표면 없는 후보, 다른 정답이 섞인 문맥, 변화가 없는 후보는 명시적으로 제외한다.
- 후보별 원본/생성/참조/마스크, 픽셀 변경 영역, 시드와 좌표, 해시, 검수 상태가 저장된다.
- 데스크톱에서 분석/생성/원본 확대 비교/마스크 편집/승인/별도 학습 프로젝트 저장까지 연결했다.
- 기존 Data Gen과 검수 잠금, 작업 종료 대기, Windows EXE 모듈 목록을 연결했다.

## 검토 중 발견해 수정한 사항

1. Qt 기본 `event()`와 작업 이벤트 콜백 이름 충돌 → 콜백 이름 분리, 실제 창 생성 시험.
2. 새 모듈의 PyInstaller 인자 연결 → 각 모듈을 `--hidden-import`로 지정.
3. 넓은 접합부 때문에 얇은 균열 가지를 놓칠 수 있는 두께 판단 → 거리 능선에서 국소 두께 확인.
4. 반복 칩/균일 배경에서 탐색이 왼쪽 위에 몰림 → 허용 영역·기존 정답을 탐색 점수에서 미리 제외하고 시드 기반 동률 분산.
5. 클래스를 변경한 뒤 과거 기록 때문에 새 분석도 열리지 않을 수 있음 → 현재 클래스와 맞는 기록만 목록에 표시, 직접 오래된 기록 로드는 거부.
6. 같은 편집 창의 두 번째 저장이 오래된 검수 버전으로 처리됨 → 첫 저장 후 버전 갱신, 실제 창 연속 저장 검사.

## 적용 한계

참조 합성은 적은 실불량 예시를 변형·재배치하는 기능이다. 실제 데이터의 정확도 개선은 이 검사로 입증하지 않았다. 인접한 같은 클래스 연결 영역은 인스턴스 정보 없이 묶을 수 있으므로 구조 결함은 검수해야 한다. 8bit RGB/흑백을 지원하며 16bit는 조용히 변환하지 않고 거부한다. 새 UI는 데스크톱에만 추가했다. 기존 모델의 추론/ONNX 경로를 수정하지 않았으며, 생성 데이터와 기존 공통 로더의 연동을 U-Net Lite로 검증했다.
