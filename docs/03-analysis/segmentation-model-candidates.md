## 리뷰에서 수정한 사항

- ShuffleNetV2의 고정 공간 크기 Reshape가 INT8 보정용 작은 패치를 거부했다.
  내부 Shape 연산을 보존하고, 외부 ONNX 입출력 크기만 배포 크기로 고정했다.
- 전역 풀링 뒤 BatchNorm은 배치 1에서 학습할 수 없었다.
  해당 단일 값일 때만 running statistics를 사용하고 affine 파라미터는 계속 학습한다.
- STDC 경계 목표는 클래스 번호의 크기에 영향받지 않도록 클래스 불일치로 만든다.
  255 영역과 인접 픽셀을 경계 손실에서 제외한다.
- auxiliary loss 설정은 체크포인트/CSV에 기록하고, 주 출력만 검증·best 선정·배포에 사용한다.
- 검증 후 한 번 발생한 macOS 프로세스 종료 오류는 크래시 스택상 ORT 1.29 telemetry
  HTTP 응답 스레드의 mutex 파괴 경쟁이었다. 모델 출력 오류가 아니었다.
  테스트 수집 시점에 telemetry를 비활성화한 재실행에서 89개 통과·정상 종료를 확인했다.
  제품의 CPU 세션 생성 경로에는 이미 telemetry 비활성화가 적용되어 있다.
