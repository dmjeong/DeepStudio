# 15.88 회귀 오류 조사 / 15.89 수정

## 확인한 실패

15.88의 main `16fb7e4` CI 실패 로그를 기준으로 재현했다.

- 학습 화면: Dinomaly 재개용 에폭 제어를 모든 엔진에 적용해 EfficientNet 재개에서도 수정 가능했다. 기존 엔진 계약을 복원했다.
- EoMT: 보조 쿼리 손실에서 패딩된 특징을 원본 크기로 바로 줄였다. 31×45, 75×110, 640×640에서 무시 영역(255)만 덧붙여도 손실이 달라지는 것을 재현했다. 디코딩 후 원본 영역을 잘라 손실과 기울기가 모두 일치하도록 수정했다.
- Linux native 비교: Python ORT 1.31.1 / C++ ORT 1.29.0이었다. 설치 버전을 고정하고 테스트 시작 시 실제 native 버전도 대조한다. 양쪽 스레드 수도 1로 맞춘다. macOS에서는 버전 차이만으로 실패가 재현되지 않았으므로 x86 결과를 별도로 확인한다.
- 원본 크기로 복원한 anomaly float 표시 맵: OpenCV 4.10 x86 / Python OpenCV 5.0의 좌표 반올림 차이 최대 7.66e-6. 이 표시 단계에만 1e-5 범위를 적용한다. 모델/타일 스코어, 마스크 클래스 일치, 암호화 전후 일치 검사는 별도로 유지한다.
- Windows: C++ 컴파일은 성공했지만 검사 데이터 생성 Python에 ONNX가 없었다. CMake 인터프리터를 명시했다. 별도 예제는 OpenCV, 수치 회귀는 SciPy가 누락되어 설치 목록을 수정했다.
- Ubuntu 최신 이미지가 26.04로 변경되어 Playwright 1.55 설치 실패. 브라우저 작업은 24.04로 고정했다.
- 전체 검사에서 드러난 구형 테스트 대역(augmentation_info 누락), 신규 builtin_resume 미반영, 실제 원본 파일이 없는 히트맵 픽스처를 현재 실행 계약에 맞게 수정했다.

## 확인 절차

1. 기존 실패를 보존하고 전체 Python 회귀 검사를 실행한다.
2. 기본 모델 RGB/BW8 실제 사전학습 → 학습 → FP32/INT8 → 암호화 → C++ 결과를 비교한다.
3. EoMT 홀수·640 입력의 정답 좌표/기울기 및 기존 재개 화면을 별도로 검사한다.
4. 검토 브랜치에서 Linux/Windows CI를 실행하고 실패 원인을 확인한 뒤 main에 반영한다.

## 검토 브랜치 중간 검증

- macOS 전체 회귀 1,555개 통과 / 76개 환경별 제외. 새 모델·화면 65개, Dinomaly 비패치 RGB/BW8 2개, EoMT 좌표 회귀 3개 통과.
- C++ CTest 7개 통과, 실제 사전학습 가중치의 FP32/INT8/암호화 비교 통과. Linux x86 CI의 같은 비교도 통과했다.
- Windows VS2017 C++17 예제 및 segmentation 평가 빌드/실행, C# SDK 통과. EfficientNet ONNX 수치 회귀 Windows/Linux 모두 통과.
- React 단위 검사 14개 및 ZIP을 푼 실제 브라우저 흐름 통과. 구형 접근성 레이블을 찾던 브라우저 검사 코드를 현재 화면에 맞췄다.
- Linux 전체 검사에서 사전학습 파일 부재 예외가 `RuntimeError`에서 `FileNotFoundError`로 바뀐 것을 반영하지 못한 테스트 17개를 발견했다. 파일이 없는 일반 검사만 건너뛰며, 공식 가중치 필수 통합 단계에서는 여전히 실패시킨다. 손상된 가중치 오류는 무시하지 않는다.
- Windows GUI 검사에서 스타일시트의 기본 문자 인코딩 사용을 제거했다. Qt 앱 수명은 세션 전체로 유지하고, 중간 네이티브 종료 시에도 첫 실패를 로그에 남긴다. Windows 전체 재실행으로 확인 중이다.

## Windows 후속 실행에서 추가로 재현한 문제

- 원본 파일을 같은 크기·수정 시각으로 바꾸면 정답 저장 충돌 검사가 놓쳤다. 파일 내용을 스트리밍 SHA-256으로 비교한다. 시각과 크기를 강제로 동일하게 만든 BMP 회귀 검사로 확인했다.
- 라벨링 표 첫 열이 78px로 고정되어 Windows 글꼴에서 `R16 C08`이 잘렸다. 실제 글꼴 폭과 행 높이로 계산한다.
- PNG 레이어 삭제 테스트가 `close()`의 비동기 초안 저장 도중 즉시 `deleteLater()`하여 QThread까지 파괴했다. 초안 완료/창 닫힘을 확인한 뒤 제거한다. CI에는 네이티브 오류도 보이는 출력 방식을 적용했다.
- 새 x86 검사는 모델 비교 전에 DINOv2 발행 서버 인증서 만료로 다운로드가 실패했다. 로컬에서도 재현했다. 알려진 고정 revision의 HTTPS 미러만 재시도하며 원본 전체 SHA-256이 같은 파일만 받는다. TLS 검증을 끄거나 가중치를 변환하지 않는다.

실제 검사 데이터 정확도·Windows i7 속도는 측정하지 않았다.

후속 로컬 확인: 전체 1,576개 통과 / 78개 환경별 제외, 이후 Windows 라벨링·이미지 저장·다운로드 수정 관련 65개 통과. DINOv2 small/base 두 미러 파일을 실제 내려받아 원본 전체 SHA-256과 동일함을 확인했다. [small 미러](https://huggingface.co/WiserZhou/DINOv2/blob/9dfd89f8766edfe1343cb764c28b285be7779157/dinov2_vits14_pretrain.pth), [base 미러](https://huggingface.co/CuteGenie/dinov2-vit-b-14-distilled/blob/290640f12c1f34a55927ffaaabe765c83db251bd/dinov2_vitb14_pretrain.pth). 원본 가중치와 라이선스를 그대로 사용하며 미러의 별도 모델을 채택하지 않는다.
