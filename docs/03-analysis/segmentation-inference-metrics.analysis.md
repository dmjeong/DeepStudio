# 세그멘테이션 추론 평가 검증

## 코드 원인 및 변경

`InferenceOperations._run_custom_inference`가 분할 출력의 argmax와 예측 픽셀 수만 결과에 넣었다. 학습 평가의 `SegmentationMetrics`는 존재했지만 추론에서 정답을 찾아 비교하는 연결이 없었다. Qt는 그 픽셀 분포만 표시했다.

공통 평가 모듈을 통해 기존 semantic 출력에 정답 비교를 연결했다. 프로젝트 정보는 워커 시작 시 스냅샷으로 전달한다. 모델 연산/전처리/ONNX export는 수정하지 않았다. GUI 직접 실행과 별도 프로세스가 동일한 계산 함수를 사용한다. IoU를 confidence 스코어 대신 넣지 않는다.

## 검증 항목

- 손계산 가능한 배열: IoU 1/2 및 2/3, Dice 2/3 및 4/5, 픽셀 정확도 3/4.
- 서로 다른 크기 두 이미지: 픽셀 누적 IoU 0.2. 이미지별 비율 평균 0.5가 나오지 않음.
- 255 제외/모두 255/정답 픽셀 0 클래스/잘못 예측한 클래스 반영.
- 작은 1픽셀 결함을 원본 해상도에서 비교해 배경 예측 오류로 검출.
- 크롭 밖 픽셀 제외, 원본 전체 정답 클래스 유효성 검사.
- 미라벨/외부 이미지/동명 다른 하위 폴더/손상/크기/컬러 마스크/클래스 번호/이름 순서/중복 마스크.
- 폴리곤 렌더링, 명시적으로 저장한 빈 라벨은 배경, 손상 폴리곤은 오류.
- 평가에 의도적으로 80ms를 추가해도 추론 시간에는 포함되지 않음.
- U-Net ResNet18·DeepLabV3+ ResNet34의 실제 CPU forward(무작위 초기화, 32×32, 3클래스). 별도 NumPy 교집합/합집합 계산과 일치. 모델 정확도/성능 개선을 측정한 실험은 아님.
- 프로세스 워커 JSON/캐시 저장 후 데스크톱 결과 복원.
- Qt 개별 지표/누적 표/정답 영역 클래스 필터/필터와 무관한 전체 배치 집계/분류 전환 후 초기화.
- 1280×900 offscreen 실제 Qt 위젯 캡처를 열어 표·상세·누락 상태를 확인.

## 실행

macOS ARM64 / Python 3.12 / offscreen PySide6. 추가 평가 회귀 19건. 관련 테스트 71건 통과. 첫 전체 실행에서 프로젝트 속성이 없는 기존 UI 테스트 더블의 Grad-CAM 두 경우 실패를 발견했다. 프로젝트 미선택 상태를 허용하도록 보완했고 해당 계약+새 평가 테스트 31건이 통과했다. 최종 전체 실행: **1233 passed, 12 skipped, exit 0** (149.35초). `git diff --check` 통과.

Windows 실기 화면/사용자 보안 이미지/학습 가중치에서는 실행하지 못했다. SAM2 프롬프트 다중 그래프 및 배포 SDK는 이번 기능 대상이 아니다. 기존 기록은 평가 미실행으로 보존하며, 새 지표를 얻으려면 프로젝트에서 다시 추론한다.
