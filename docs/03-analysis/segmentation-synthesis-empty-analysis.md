# 14.87 — 분석 0개와 생성 무반응 검증

## 사용자 증상과 확인 범위

사용자는 ‘분석이 끝난 뒤 Train 참조가 모두 0, 클래스당 미리 생성에 반응 없음’이라고 확인했다.
사용자 PC의 상세 오류/실제 정답 데이터는 제공되지 않았으므로, 해당 데이터의 직접 원인을 확정하지 않았다.
현재 저장소의 성공 경로만 시험한 것이 부족했다. 아래 실패·복구 경로를 코드와 실행으로 확인해 수정했다.

## 재현한 결함

1. **분석과 자동 데이터 스캔의 경합**: `scan_dataset`과 분석이 같은 `project_edit_lock`을 사용하며 잠금은 즉시 실패한다. 분석 워커가 자동 스캔 종료를 최대 30초 기다리게 수정했다. 대기 진행 문구 및 취소를 시험했다.
2. **참조 선택 복원 누락**: 한 번 0개여서 체크 해제된 클래스가 참조 1개가 되어도 체크되지 않았다. 새 분석/분할 및 새로 사용 가능해진 클래스는 기본 선택하며, 같은 문맥의 수동 선택은 보존한다.
3. **과도한 주변 영역 제외**: 20×20 shift 정답에서 8px 떨어진 이물 때문에 shift 참조가 0개가 됐다. 이전 코드 0개 / 수정 코드 1개를 직접 비교했다. 정상 문맥을 충분히 유지할 수 있을 때만 주변 폭을 줄이며 다른 정답이나 255 영역은 포함하지 않는다. 바로 맞닿은 이물은 계속 제외된다.
4. **실패가 보이지 않음**: 화면 하단 QLabel 하나로 끝나던 오류를 상단 요약·비차단 오류 창·분석 상세·내용 복사로 연결했다.
5. **완료 오표시**: refresh 오류를 잡은 뒤 완료 메시지로 덮거나, 분석 실패 뒤 예전 profile을 선택할 수 있던 자동 흐름을 수정했다.

## 저장되는 진단

성공 시 profile과 작업 결과, 실패 시 작업 결과 및 `segmentation-analysis.json`에 다음을 남긴다.

- 실제 이미지/마스크/폴리곤 폴더
- 분할별 읽은 이미지 수, 정답 파일이 있는 이미지 수, 불량 포함 이미지 수
- 클래스별 불량 픽셀 수, 연결 영역 수, 사용 가능한 참조 수
- 주변 다른 정답, 테두리, 정상 문맥 부족으로 제외된 수
- 처리 중이던 이미지와 실제 오류 문구

실패 결과는 정상 profile로 공개하지 않는다. 정답 파일 미발견, 배경/제외 영역뿐인 정답, 불량은 있으나 모두 제외되는 경우의 문구를 구분했다. 실행 모듈 실패 등 보고서를 만들기 전 실패는 실행 로그도 상세 창에 표시한다.
