# Studio 정리 검증

요구사항별 확인:
- 앱 루트, C++ 헤더/구현/API/CMake, Python 모델, GUI/웹/CI/배포 경로를 현재 명칭으로 통일했다.
- 폐기된 외부 엔진의 학습/추론/다운로드/선정/내보내기 어댑터와 전용 테스트를 제거했다.
- 분류(EfficientNet·Custom CSP), 자체 탐지/시맨틱 분할/재구성, PatchCore와 데이터 편집은 유지한다.
- 회전 박스는 편집과 크롭만 지원하며 학습은 명시적으로 거부한다.
- 기존 저장 모드를 현재 엔진으로 조용히 바꾸지 않는다. 지원하지 않는 모드는 선택 화면에서 확인할 수 있다.
- 모델 수치 검증 실패 시 자동 모드의 PyTorch 추론 복구와 명시적 내보내기의 검증은 유지한다.
- 새 프로젝트는 .dvproj로 저장한다. 기존 JSON 프로젝트는 모든 파일 필터로 선택하여 읽을 수 있다.

검증 결과: Python 589 통과/11 건 환경별 생략, 웹 11 통과와 TypeScript/Vite 빌드,
FastAPI 정적 자산 및 API smoke 통과. C++17 Release는 ONNX 단독 및 OpenVINO 포함
두 구성에서 각각 CTest 3/3 통과했다. 실제 모델 내보내기/재로딩 및 작업자 계약도 포함한다.
테스트 장비는 macOS ARM64이며 Windows 실행 및 i7 지연시간 달성 검증은 아니다.

폐기한 엔진만 사용하는 테스트는 제거했으며 자체 공간 태스크 테스트의 외부 패키지 조건은
제거하여 실제 실행되도록 했다. 사용자 모델과 이미지는 사용하거나 업로드하지 않았다.
현재 추적 파일 내용과 경로를 대상으로 잔재를 검사한다. Git 과거 이력은 재작성하지 않는다.
