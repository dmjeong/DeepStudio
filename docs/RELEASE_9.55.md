# 9.55 — 세그멘테이션 추론 평가

## 사용법

학습 당시 클래스 이름과 순서가 같은 세그멘테이션 프로젝트를 열고, 해당 프로젝트의 train/val/test 이미지를 추론합니다. 기존 라벨링 도구로 저장한 `masks/<split>/<하위 경로>/<이름>.png` 또는 `labels/<split>/<하위 경로>/<이름>.txt`를 자동으로 찾습니다. 외부 폴더의 동명 이미지는 연결하지 않습니다.

- 판정 상세: 선택한 이미지의 클래스별 IoU, Dice, 픽셀 정확도 및 예측 픽셀 수.
- 배치 표: 이미지별 mIoU/Dice와 정답 비교 상태. 값이 없는 경우 0%로 표시하지 않습니다.
- 배치 하단: 전체 배치 픽셀 수를 합산한 클래스별 IoU/Dice. 필터·행 선택은 이 집계 범위를 바꾸지 않습니다.
- 클래스 필터: 정답 마스크에서 해당 클래스 픽셀이 있는 이미지. 이미지 폴더는 클래스가 아닙니다.

## 계산 기준

IoU는 교집합/합집합, Dice는 교집합×2/(예측 면적+정답 면적)입니다. 이미지별 비율을 단순 평균하지 않고 픽셀 수를 누적합니다. 배경도 정답 픽셀이 있으면 평균에 포함합니다. 정답 픽셀 0인 클래스는 `—`로 표시하고 평균에서 제외합니다. 잘못 예측한 픽셀은 실제 정답 클래스의 오류로 반영됩니다. 255는 평가 제외입니다.

예측 마스크만 nearest로 원본 해상도에 맞추며 정답의 작은 결함을 축소해 없애지 않습니다. 중앙 크롭은 모델이 실제 본 영역만 평가합니다. 마스크 읽기·비교 비용은 `evaluation_sec`로 기록하며 추론 ms에 포함하지 않습니다(전체 작업 시간에는 포함).

## 평가 불가

마스크가 없는 이미지는 학습의 자동 배경 정책과 달리 추론 평가에서 제외합니다. 명시적으로 배경만 저장한 마스크/빈 폴리곤 파일은 평가합니다. 크기/모드/클래스 불일치나 손상 파일은 오류 원인을 보여주며 예측·미리보기는 유지합니다. 모델과 프로젝트의 클래스 이름·순서가 일치해야 합니다.

작업 기록 JSON에 평가와 집계용 카운트를 함께 보관하므로 다시 열 때 재추론하지 않습니다. 이전 버전 기록에는 정답 비교 미실행으로 표시합니다. 새 지표가 필요하면 재추론하면 되며 재학습할 필요는 없습니다.

## 범위

기존 단일 semantic 출력 추론 경로(U-Net·DeepLab·Custom CSP)와 데스크톱 프로세스/인프로세스 실행에 적용합니다. 분류·탐지·이상 탐지의 점수와 ONNX 내보내기는 변경하지 않습니다. SAM2의 별도 프롬프트 다중 그래프 실행/객체 매칭을 새로 추가한 릴리스는 아닙니다.

검증 결과는 `docs/03-analysis/segmentation-inference-metrics.analysis.md`에 기록합니다. Windows 실제 화면/사용자 검사 데이터 검증은 이 macOS 환경에서 수행하지 못했습니다.
