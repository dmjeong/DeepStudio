# Deep Vision Studio 8.3

Defect Gen 입력 경계와 저장 무결성 수정

- 평가 이미지 또는 이전 합성 이미지를 텍스처로 참조하는 경로를 차단합니다.
- 이름이 달라도 파일 내용이 같은 원본을 중복 생성 입력으로 받지 않습니다.
- 비어 있는 원본 폴더 설정이 현재 작업 폴더 탐색으로 해석되지 않게 합니다.
- 분류, 검출, 분할의 학습/평가 폴더 중첩을 차단합니다. 기존 이상 탐지 프로젝트의 정상 학습 폴더를 가리키는 val 별칭은 유지하고 실제 test 경로는 항상 차단합니다.
- 배치를 공개하기 전 이미지, 마스크, 원본 스냅샷, 생성 기록과 ZIP을 다시 읽어 무결성을 확인합니다.
- 반복 저장에서도 원본, 기록 또는 ZIP이 누락된 배치를 성공으로 처리하지 않습니다.

데스크톱 배포는 소스 태그와 GitHub 소스 압축 파일만 제공합니다. EXE 빌드와 실행 파일 첨부는 배포 작업에서 제거했습니다. React의 실행용 ZIP 배포는 유지합니다.

로컬 검증: `python -m unittest discover -s tests -p test_defect_transactions.py -v` 14개 통과. 이 테스트의 PNG 인코더는 Pillow로 대체하며, 파일 저장과 ZIP 검증은 실제 파일로 수행합니다. OpenCV 기반 생성 실행, Windows GUI, 실제 GPU 검증을 통과했다는 의미는 아닙니다. 전체 CI 결과는 해당 커밋의 Actions에서 별도로 확인해야 합니다.

현재 생성 엔진은 규칙 기반입니다. 확산 모델, LoRA 학습과 실제 검사 성능 비교는 포함하지 않습니다. 이어갈 계획은 [Defect Gen 진행 기록](DEFECT_GEN_PROGRESS.md)에 있습니다.
