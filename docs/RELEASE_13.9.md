# Desktop 13.9: 모든 태스크의 중앙 크롭

학습의 공통 입력 설정에서 중앙 크롭 사용과 가로, 세로를 지정합니다.
분류, 검출, Semantic/Instance Segmentation, PatchCore와 재구성 이상 탐지에 적용합니다.

- 원본 픽셀 기준으로 중앙을 자른 뒤 기존 리사이즈와 증강을 적용합니다.
- 검출 박스는 경계에 맞게 자르고, 크롭 밖 객체는 제외합니다.
- 픽셀 마스크의 클래스 인덱스를 보존하고 폴리곤의 교차 영역을 계산합니다.
- 원본과 train/val/test 분리는 보존하며 별도 generated 폴더에 무손실 PNG 스냅샷을 만듭니다.
- 저장 실패와 취소 시 미완료 스냅샷을 정리합니다. 완료 스냅샷은 중단 재개용으로 유지하므로 추가 디스크 공간이 필요합니다.
- Custom 및 폐기된 외부 엔진 체크포인트에 크롭을 저장하고 모델 재로드 시 추론에 복원합니다.
- 검출 결과, 분할 마스크와 히트맵은 원본 좌표에 표시합니다. 크롭 밖은 검사 대상이 아닙니다.
- ONNX JSON에 크롭을 포함하고 C++ Custom 분류/분할에서도 같은 영역을 사용합니다.
- 기존 PatchCore 프로젝트 설정은 호환됩니다. 크롭 변경 시 메모리 뱅크 재구축이나 새 추가 학습을 사용합니다.

원본보다 큰 크롭은 오류로 알립니다. 분류 및 이상 탐지의 이미지 라벨은 크롭 안의 내용과 일치해야 합니다. 크롭은 기본 꺼짐이며 타일링과 자동 정렬 기능은 아닙니다.

검증: 라벨 경계, 원본 보존, 저장 실패, 취소, Custom 네 태스크 CPU 재로드, 공식 분류/검출/분할 실제 학습 후 추론, Qt 설정 저장/복원, C++ 배포 규약을 CI에서 실행합니다. 현장 정확도나 GPU 성능은 이 검증에 포함하지 않습니다.

데스크톱 릴리스에는 소스 ZIP만 첨부합니다. EXE 바이너리는 첨부하지 않습니다.
