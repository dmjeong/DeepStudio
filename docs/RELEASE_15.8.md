# React 15.8: 모든 태스크의 중앙 크롭

학습의 공통 입력 설정에서 중앙 크롭 사용과 가로, 세로를 지정합니다.
분류, 검출, Semantic/Instance Segmentation, PatchCore와 재구성 이상 탐지에 적용합니다.

- 원본 픽셀 기준으로 중앙을 자른 뒤 기존 리사이즈와 증강을 적용합니다.
- 검출 박스는 경계에 맞게 자르고, 크롭 밖 객체는 제외합니다.
- 픽셀 마스크의 클래스 인덱스를 보존하고, 폴리곤은 교차 영역을 계산해 분리된 영역을 유지합니다.
- 원본과 train/val/test 분리는 보존하며 별도 generated 폴더에 무손실 PNG 스냅샷을 만듭니다.
- 스냅샷 준비 중 취소나 저장 실패 시 미완료 폴더를 정리합니다. 완료 스냅샷은 중단 재개를 위해 유지하므로 추가 디스크 공간이 필요합니다.
- Custom 체크포인트와 폐기된 외부 엔진 Best/Last에 크롭 설정을 저장합니다. 모델 재로드 시 CPU/GPU 추론에도 복원합니다.
- 박스, 마스크와 히트맵을 원본 좌표에 복원합니다. 크롭 밖은 검사 대상이 아닙니다.
- ONNX JSON에 크롭 규약을 포함합니다. C++ Custom 분류/분할은 크롭 전처리와 분할 유효 영역을 지원합니다.
- PatchCore 저장 프로젝트의 기존 설정을 그대로 읽습니다. 메모리 뱅크 추가와 중단 재개 시 크롭 변경은 거부합니다.

크롭은 기본 꺼짐입니다. 원본보다 큰 크기는 오류로 알립니다. 분류 및 이상 탐지의 이미지 라벨은 크롭 안의 내용과 일치해야 하며 자동 재분류하지 않습니다. 타일링이나 대상 위치 자동 정렬은 아닙니다.

검증: 독립 스냅샷, 경계 박스, 오목 폴리곤 분리, 팔레트 마스크, 실패 정리, Custom 네 태스크 CPU 재로드, 공식 분류/검출/분할 실제 학습과 저장/추론, Qt와 React 설정 저장/복원, C++ 배포 규약을 CI에서 실행합니다. 실제 현장 이미지의 정확도 및 GPU 성능 수치는 포함하지 않습니다.

개발 참고: [폐기된 외부 엔진 trainer API](https://github.com/dmjeong/Vision)의 저장 확장 지점과 [Shapely intersection](https://shapely.readthedocs.io/en/stable/manual.html#object.intersection)을 사용합니다.
