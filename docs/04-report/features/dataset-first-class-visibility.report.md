# 9.44 완료 보고 — 데이터셋 첫 클래스

등록 클래스 목록을 전경 편집 목록과 분리하여 첫 이름을 통계·필터에서 누락하던 문제를 수정했다.
구형 프로젝트의 0번 결함 이름도 표시하며 복구 필요 상태를 안내한다. 저장된 ID와 원본 마스크를
조회만으로 변경하지 않고, 기존 복구 동작 후 같은 클래스 필터와 실제 영역 수를 표시한다.

- 전체 테스트 1,196 통과 / 12 건너뜀.
- 새 회귀 테스트 7 통과. 수정 전에는 이 중 6건으로 누락을 재현.
- 실제 Qt 비동기 스캔 및 복구 버튼을 실행하고, 신규·기존·복구 후 화면을 확인.
- Ruff와 diff 공백 검사 통과. Windows 실제 실행은 수행하지 않음.
- 릴리스 9.44 (+0.01). 변경 범위는 데이터셋 UI·테스트·버전·문서이며 학습/추론 연산은 변경하지 않음.
