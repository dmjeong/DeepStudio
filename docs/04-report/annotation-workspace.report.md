# 9.23 라벨링 작업실 개발 결과

작성일: 2026-10-22. 상태: 로컬 기능 구현과 검증. Windows 설치본 수락 대기.

Detection과 Segmentation의 편집창을 공통 작업실로 전환했다. 모델마다 다른 라벨링 흐름을 만들지 않고, 클래스 등록·다중 선택·지우개 범위·다각형 수정·Undo·저장을 같은 방식으로 사용한다.

추가한 기능은 브러시 픽셀 선택, 기존 PNG의 연결 부분 분리, 잠금·숨김, 실제 픽셀 기준 확대, 단축키 변경, 화면 전용 밝기·대비, 8×16 격자와 아핀/원근 기준점, 원본과 정답 변경 검사, 자동 초안과 강제 종료 복구, 로컬 SAM2 제안이다. 초안·미확정 AI 제안은 학습 정답에 자동 반영하지 않는다.

저장 후 창을 유지하며, 저장 도중 새 편집이나 저장 실패를 완료로 잘못 표시하지 않는다. 무시 영역 255와 구멍은 저장·재열기·실제 Segmentation 학습 로더에서 동일하게 유지한다. 새 편집 정보는 표준 클래스 번호 PNG에 포함하고, 구형 웹 편집기의 정보 손실을 막기 위해 읽기 전용으로 제공한다.

최종 테스트 집계와 성능·메모리·실제 SAM2 실행 결과, 계획 조정과 출시 전 조건은 [구현 분석](../03-analysis/annotation-workspace.analysis.md)에 기록했다. [사용법](../ANNOTATION_WORKSPACE.ko.md)과 [실제 실행 화면](../02-design/assets/annotation-workspace-implemented.png)을 함께 제공한다.

Windows 실행 파일은 새로 빌드하지 않았다. 소스 반영 기록은 Git 이력을 기준으로 한다.
