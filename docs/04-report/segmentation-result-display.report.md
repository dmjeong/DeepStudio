# 9.56 표시 수정 보고

사용자 의도는 원본 위에 검출한 영역과 클래스를 표시하는 것이었다. IoU 표만 추가한 이전 작업으로 해결되지 않았고, 실제 표시 코드가 배경까지 색칠하고 Grad-CAM을 기본 선택하는 문제를 확인해 수정했다.

- 배경/구멍 원본 유지, 예측 전경만 채움과 윤곽, 각 영역의 한글 클래스명 표시.
- 분할 기본 Grad-CAM 해제 및 별도 보기. 정답이 없어도 예측은 표시.
- 원본 비교·격자·중앙 크롭·확대·캐시 복원을 점검하고 실제 Qt 화면을 캡처.
- 관련 110건 및 최종 전체 1244건 통과, 12건 skip, exit 0.
- 새 그림은 재추론 필요, 재학습 불필요. 기존 캐시의 붉은 픽셀을 새 모델 출력인 것처럼 바꾸지 않음.

모델별 기능 확인은 별도이며 완료로 표시하지 않는다. U-Net 공식 사전학습 1ch/3ch 학습→저장→재로드→추론→Qt 실행을 합성 데이터로 확인했다. SAM2 일반 추론 거부와 binary prompt/semantic 계약 불일치를 재현했다. 사용자 Windows U-Net 실패 단계/문구는 아직 받지 못했다. `segmentation-model-readiness-audit`를 열린 상태로 남긴다.
