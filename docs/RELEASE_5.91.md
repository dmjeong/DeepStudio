# 5.91 — 저장된 Best epoch 지표 표시

## 계획과 설계
종합 지표의 태스크별 고정 목록을 제거한다. 대시보드와 평가 표 모두 실제 Best 에폭의
동일한 지표 묶음을 표시한다. 전체 평가 결과를 기본으로 읽고 Best 에폭 이력, 저장 당시
스냅샷, 실제 선정 지표 순으로 적용한다. 다른 에폭 값이나 없는 지표를 만들어 채우지 않는다.
학습 중에는 best_epoch_updated만 지표를 갱신하고 최근 에폭 시간은 별도로 갱신한다.
Qt·웹 화면, 기존 프로젝트 재열기와 이어학습을 검사한다.

## 구현
공통 Best 지표 조회, 동적 카드·평가 표, 저장 시 지표 스냅샷, 모델별 실제 에폭 번호 보존.
`best_result.csv`와 `best_selection.json`도 동일한 지표 묶음을 기록한다.
모델 선정 지표는 저장된 원본 정밀도를 유지하고, 화면에서만 소수점 넷째 자리까지 표시한다.

## 검증
분류·검출·분할·SAM2·PatchCore 저장 기록으로 CSV와 재열기 지표 일치를 검사했다.
실제 Qt 위젯에서 Best 이후 에폭 이벤트가 대시보드 값을 바꾸지 않는지,
고정 지표가 남지 않는지와 평가 이력이 없는 모델 표시를 검사했다.
웹에서도 같은 Best 에폭 복원·이벤트·저장 스냅샷 우선순위를 검사했다.
가중치 학습 알고리즘과 Best 선정 규칙은 변경하지 않는다.
