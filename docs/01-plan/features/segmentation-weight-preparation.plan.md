# 세그멘테이션 기본 가중치 준비 복구

사용자 증상: DeepLab 외 모델 선택 시 모두 가중치가 없다고 표시. Windows Python 실행 환경이며 원격 PC의 실제 누락 파일/다운로드 로그는 확보하지 않았다.

확인한 결함: Python 실행 안내가 가중치 준비를 생략한다. 준비 도구의 상대 출력 경로와 런타임의 환경변수 경로가 달라질 수 있다. SAM2 다운로드는 공통 Windows 인증서 다운로드기를 사용하지 않으며 수동 공식 파일도 manifest 없이는 거부된다. SAM2에도 불가능한 scratch 모드를 해결책으로 안내한다.

목표: 모든 기본 가중치를 한 번에 준비하고, 세그멘테이션만 복구할 수도 있게 한다. EXE 재빌드를 요구하지 않는다. 준비 경로와 로드 경로를 통일하며 누락/손상 원인을 구분한다. 기존 파일, SSL 및 해시 검증은 보존한다.

검증: 누락/부분 완료/경로 override/오프라인 등록/손상/인증서 오류 회귀 검사, 공식 ResNet18 및 SAM2 4종 다운로드·해시·실제 모델 로드. Windows 배치 실행과 사용자 PC의 다운로드 실패 원인은 이 macOS 검사와 구분한다.
