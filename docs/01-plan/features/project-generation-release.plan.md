# 프로젝트 클래스별 데이터 생성과 Windows 배포 검증

2026-11-12

## 요구사항

- 설치 대상 PC에 Python을 따로 설치하지 않고 EXE를 실행한다.
- 프로젝트에 등록한 클래스 이름을 그대로 사용한다. 생성 기법과 검사 클래스를 분리한다.
- classification / segmentation / object detection / OBB / anomaly detection의 출력 형식을 각각 지원한다.
- 새 이미지를 저장한다. 원본·정답을 덮어쓰지 않는다. 합성 결과는 확인 후 저장한다.
- 이상검출용 합성 불량은 정상 학습 데이터에 넣지 않는다.
- 기존 SEG 참조 기반 생성과 학습형 Data Gen은 유지한다.
- 패치 학습과 입력 크기의 관계를 현재 코드에 맞춰 그림·코드로 설명한다.

## 확인된 결함

- main b483131 Windows 회귀가 정답 연결 UI 테스트 도중 종료된다.
- Windows C++ 예제의 한글 경로 복사 실행이 access violation으로 실패한다.
- PyInstaller에서 신규 모델 모듈 hidden import를 찾지 못하는데도 빌드가 계속된다.
- 기존 생성 도구가 검사 클래스·생성 기법·태스크별 저장을 일관되게 연결하지 않는다.

## 완료 기준

- 실제 Windows EXE 빌드 및 설치/실행 스모크가 통과한다.
- 모든 태스크에서 사용자 정의 한글 클래스의 생성/검수/저장과 재읽기를 검사한다.
- 마스크·박스·클래스 ID, 원본 보존, split, 취소, 재실행, 오래된 클래스 설정을 회귀 검증한다.
- 로컬 전체 회귀와 Windows CI 결과를 기록한다. 실제 검사 정확도나 모든 버그 제거를 보증하지 않는다.
