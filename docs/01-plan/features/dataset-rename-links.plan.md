# 데이터셋 이미지 이름 변경과 정답 연결 복구

사용자 재현: Windows 탐색기에서 기존 학습 이미지의 이름을 바꾸고 프로젝트 저장을 눌렀으나, 학습 시 `마스크에 대응하는 이미지 누락`이 계속 발생한다.

확인: 정답은 이미지의 상대 경로와 확장자를 제외한 이름으로 연결한다. 프로젝트 저장은 설정만 저장하며 이름 변경 이전의 이미지 신원을 기록하지 않는다. 따라서 이전 이름의 마스크가 남고, 새 이미지는 정답 없는 이미지로 보인다. 현재 로더는 중단하지만 화면에는 연결이 끊긴 정답을 표시하거나 복구하는 기능이 없다.

목표:
- 연결이 끊긴 정답을 데이터셋 화면에서 즉시 찾고, 사용자가 선택한 새 이미지에 원본 정답을 백업 후 연결한다.
- 앱 내 이미지 이름 변경은 마스크/박스/폴리곤 정답을 함께 변경한다.
- 프로젝트 저장 후 외부 변경을 다시 스캔한다. 저장만으로 복구됐다는 오해를 없앤다.
- 잘못된 연결을 추측하거나 불량을 자동 배경 처리하지 않는다. 기존 정답·충돌 파일을 덮어쓰지 않는다.
- 실패와 중단에 대한 기존 트랜잭션 백업·복구를 유지한다.

검증: 탐색기 이름 변경→프로젝트 저장→복구 UI→일반/패치/크롭 학습 데이터 로드, 동일 픽셀 및 메타데이터 보존, 다른 크기/클래스/분할/중복/충돌/쓰기 실패, Detection 정답 동반 변경, 실제 Qt 조작.

추가 사용자 보고: SCTNet 및 다른 신규 모델 학습 시 `No module named timm`. 설치 목록에는 이미 timm이 있으나 기존 Python 환경의 소스 업데이트는 설치를 실행하지 않는다. 모든 timm 모델 생성 경로에 실제 import 사전 검사와 현재 Python 경로/복구 방법을 표시하고, PyTorch/CUDA·가중치 재설치 없는 배치 복구를 제공한다. SCTNet의 단일 DropPath 의존은 동등 PyTorch 구현으로 제거한다.
