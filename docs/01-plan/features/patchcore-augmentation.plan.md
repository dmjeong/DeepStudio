# PatchCore 증강 및 코어셋 진행 정보

사용자 요청: 코어셋 비율을 바꿨을 때 소요시간/실제 적용 여부를 확인할 수 있어야 하며 PatchCore 데이터 증강을 편집하고 학습에 적용해야 한다.

- 원본 정상 이미지를 보존하고 원본당 추가 증강 수를 명시한다. 기존 프로젝트 기본값 0으로 기존 동작을 유지한다.
- 좌우 반전·회전·색상 변화를 정상 특징 수집에 연결한다. 검증·추론에는 증강하지 않는다.
- 요청한 대표 특징 수와 후보/메모리 한도로 제한된 실제 수를 표시하고 특징 추출/코어셋 선별 시간을 따로 기록한다.
- 변경한 설정, 실제 적용 내역을 프로젝트·체크포인트·학습 CSV에 남긴다.
- 모델의 추론 연산이나 기존 점수·임계값 정의는 변경하지 않는다. 비율 증가가 항상 정확도/속도를 개선한다고 주장하지 않는다.

검증: 결정적 증강·원본 보존·검증 미적용·UI 저장복원·워커 전체 실행·제한/추가학습 개수·실측 로그 및 기존 배포 회귀.
