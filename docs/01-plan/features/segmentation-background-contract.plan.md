# 세그멘테이션 첫 클래스와 자동 배경 학습

사용자 요구(2026-10-29): Claude 최신 브랜치를 확인해 첫 클래스 등록을 고치고, 라벨을 만들지 않은 이미지도 기본적으로 배경으로 학습한다. 구현·검증 후 main에 푸시한다.

## 확인된 결함
- 프로젝트 생성/클래스 추가가 첫 사용자 클래스를 ID 0으로 저장한다. 편집기와 학습기는 0을 배경으로 처리한다.
- Claude 89b6ae0은 미라벨 이미지를 학습에서 제외한다. 사용자 요구와 반대다.
- SAM2는 배경 샘플을 건너뛰며 ignore 픽셀도 이진 변환에서 손실될 수 있다.
- 데이터 화면의 미라벨 문구는 실제 학습 포함 여부를 설명하지 않는다.

## 범위와 합격 조건
1. 새 프로젝트/빈 기존 프로젝트에서 배경을 자동 예약하고 첫 결함을 ID 1로 저장·재열기·그리기·재분류한다.
2. 기존 프로젝트의 유효한 클래스 ID와 마스크를 조용히 재번호화하지 않는다. 잘못된 첫 클래스의 복구 동작을 제공한다.
3. U-Net, DeepLab, 커스텀 semantic 및 SAM2의 train/val, 중앙 crop에서 미라벨 이미지를 배경으로 포함한다.
4. 실제 라벨/ignore/손상 마스크는 배경으로 대체하지 않는다. source 폴더에 자동 마스크를 쓰지 않는다.
5. 데이터 UI·로그에 자동 배경 개수를 표시한다. 기존 확인된 배경과 미라벨 상태는 구분한다.
6. 생성 데이터로 UI 입력, 실제 학습, 저장/재로드, 관련 회귀 검사를 실행한다. Windows/CUDA 미실행 범위를 명시한다.
