# DINOv2 세그멘테이션 기본 모델 추가

날짜: 2026-10-29. 대상 버전: 10.57 (신규 모델 +1.0).

## 목표와 범위
- 공식 DINOv2 ViT-S/14 (LVD-142M, register 없는 21M 백본)를 기본 모델로 제공한다.
- GPU/CPU 학습, 사전학습/로컬 전이/무작위 초기화, 저장/복원, 추론 표시,
  ONNX 및 암호화 배포까지 기존 built-in segmentation 경로에 연결한다.
- 1채널 BW8/3채널 입력과 이미지 안의 클래스별 마스크를 지원한다.
- build/setup/weights 도구에서 공식 가중치를 준비하고 실행 중에는 다운로드하지 않는다.
- 작은 특징을 위해 원본 해상도의 얕은 CNN 경로를 유지한다. 백본의 패치화가
  작은 결함을 반드시 보존한다고 주장하지 않는다. 실제 검사 정확도는 별도 평가 대상이다.

## 완료 기준
1. 공식 가중치 strict load와 공식 구현 대비 특징 일치.
2. 홀수/직사각형/패치 비배수 입력에서 원래 크기의 픽셀별 logits 출력.
3. 실제 학습→best/last 저장→재개/추론→ONNX→암호화 로드의 기능 테스트.
4. 앱 모델 선택/학습 모드/가중치 안내/설치 카탈로그에 일관된 등록.
5. 기존 회귀 검사 통과, 실제 CPU 지연시간과 측정 조건 기록.
6. Apache-2.0 라이선스/출처/가중치 SHA256 고정. 실행 시 torch.hub나 xformers 불필요.

## 한계
비공개 검사 데이터는 요구하지 않는다. 합성 데이터는 기능 검증에만 사용한다.
Windows/CUDA 장비가 없는 환경의 결과를 해당 장비 검증으로 표시하지 않는다.
원본 128칩 전체 20ms, 정확도 개선, 모든 하드웨어의 성능은 보장하지 않는다.
