# 사전학습 가중치 설치 복구 — 계획

- 문제: 준비 스크립트가 모든 모델 다운로드 이후에만 manifest를 저장하므로 중간 실패 시 완료한 모델도 사용할 수 없다.
  수동 설치한 공식 ResNet 파일 역시 manifest 부재로 거부된다. 사용자 PC의 구체적인 다운로드 실패 원인은 로그 없이는 확정하지 않는다.
- 범위: 모델별 진행·실패 안내, 완료 파일의 증분 등록, 공식 Torchvision 파일의 오프라인 인식/등록, Windows 배치 복구 도구.
- 성공 조건: 다른 모델 실패에도 ResNet 준비를 시도하고 성공 항목은 남는다. 공식 해시가 맞는 수동 파일은 앱에서 인식된다.
  손상 파일, 기존 manifest 해시 불일치, 비공식 파일은 통과시키지 않는다. 불완전한 전체 빌드는 실패를 반환한다.
- 추가 확인: ResNet50의 실제 다운로드(V1)와 학습 provenance(V2)가 불일치하므로 공식 V2 파일로 일치시킨다.
- 검증: 중간 실패/재시도/쓰기 중단/수동 등록/manifest 손상 회귀 테스트, 실제 공식 ResNet 다운로드·로드·순전파.
