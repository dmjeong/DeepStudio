# 추론 세그멘테이션 평가 표시

- 사용자 요청: 추론 화면의 판정·배치 결과에 클래스별 IoU 등 표시.
- 원인: 추론은 argmax 마스크와 픽셀 분포만 반환하며 정답 비교를 호출하지 않는다.
- 범위: 기존 semantic 분할 추론의 공통 경로, 프로세스 워커, Qt 판정/배치 UI, 결과 JSON 복원.
- 합격: 정답 PNG 또는 폴리곤이 있는 프로젝트 이미지의 클래스별 IoU/Dice 및 배치 누적 지표. 미라벨은 평가 불가이며 자동 배경으로 간주하지 않는다.
- 모델 재학습/출력/ONNX export 변경 없음. SAM2의 별도 프롬프트 다중 그래프 실행을 새로 구현하는 범위는 아님.
