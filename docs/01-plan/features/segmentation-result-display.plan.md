# 분할 결과 표시 수정

사용자 정정: 필요한 것은 원본 이미지에 찾은 영역과 클래스를 표시하는 기능이다. 전체를 붉게 덮는 화면과 평가 수치만 추가하는 것으로 해결되지 않는다.

원인: segmentation_preview가 배경 0까지 팔레트로 혼합한다. 분할 모델도 Grad-CAM 기본 체크 상태를 이어받아 실제 분할 마스크 대신 전체 반응 맵을 표시한다.

목표: 배경 픽셀 그대로, 예측 전경만 채움/윤곽, blob별 클래스 이름, 기본 Grad-CAM 해제 및 별도 선택. 정답 없이도 표시. 단일/격자/캐시/중앙 크롭/한글 이름 검증.
