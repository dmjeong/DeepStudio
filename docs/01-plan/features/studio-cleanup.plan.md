# Studio 코드 및 이름 정리

사용자 요청: 폐기한 외부 모델 엔진의 코드, 학습/추론 설정, 테스트, 문서와 이름을
모든 언어 및 파일/폴더 경로에서 제거한다. 앱 루트는 DeepVisionStudio로 통일한다.

분류의 EfficientNet/자체 모델, 자체 시맨틱 분할·박스 탐지·재구성 이상 탐지,
PatchCore와 데이터 편집 기능을 보존한다. 지원하지 않는 회전 탐지 학습은 명확히 거부한다.
기존 사용자 모델/이미지를 삭제하지 않고 현재 저장소의 소스와 배포 구성을 정리한다.

검증: 추적 파일 경로/내용 잔재 검사, Python/Qt 태스크 회귀, 웹 타입/테스트/빌드,
C++17 Release/CTest, 패키지 경로와 실제 분류·분할 추론. 완료 후 deepstudio3에 push한다.
