# 8.21 — SAM2 분할 데이터 사전 검사와 클래스 안내

SAM2 학습이 데이터 구성 오류와 배경 전용 마스크 때문에 시작하지 못하는 경우를 빠르게 설명하고, 데이터셋 화면에서 클래스 설정과 영역 라벨링을 구분하도록 보강했다.

- train/val에 이미지와 대응하는 단일 채널 마스크가 있는지, 마스크 크기·클래스 범위가 유효한지, 전경 클래스가 있는지 모델 가중치를 불러오기 전에 확인한다.
- 클래스 ID 0은 배경, 1 이상은 전경, 255는 제외 픽셀이라는 규칙을 학습 화면에서 안내한다.
- 255 픽셀을 SAM2 손실과 Prompt Dice/IoU에서 제외한다.
- 데이터셋 화면에서 클래스는 라벨 전에 추가할 수 있고, 이미지별 영역에는 폴리곤/브러시 마스크가 필요함을 안내한다.
- 기존 라벨이 없는 이미지의 일괄 클래스 변경을 비활성화하고 API에서도 무변경 작업을 거부한다.

검증: `python -m py_compile` 통과, 웹 TypeScript/Vite production build 통과. pytest는 이 작업 환경에 설치되지 않아 실행하지 못했다.
