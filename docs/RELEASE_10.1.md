# Deep Vision Studio 10.1

Defect Gen 1단계: 후보 생성, 검수 및 안전한 저장

- 합성 후보를 독립 작업 폴더에 보관하고 선택한 이미지를 재생성 없이 저장합니다.
- 원본, 합성 결과, 실제 변경 마스크를 비교하고 지난 작업을 복원할 수 있습니다.
- 검수 결과는 별도 synthetic 폴더로 저장하며 학습/검증/평가 폴더 직접 저장을 차단합니다.
- 이미지, 마스크, 원본 스냅샷, 생성 기록과 ZIP을 완료된 배치로 함께 공개합니다.
- 저장 실패 시 불완전한 배치를 공개하지 않고 취소 전 완료한 후보를 보존합니다.
- 같은 원본과 시드는 미리보기와 배치의 첫 결과에서 같은 픽셀을 생성합니다.
- ROI 크기 불일치를 오류로 안내하고 프로젝트별 생성 설정을 복원합니다.
- EXE와 React는 공통 생성 엔진을 사용합니다.

현재 생성기는 규칙 기반 표면 합성입니다. 확산 모델과 LoRA 학습은 후속 단계이며 이 버전에 포함되지 않습니다.
변경 마스크는 픽셀 차이를 기록한 자료입니다. 학습 정답으로 사용하려면 실제 불량 영역을 별도 검수해야 합니다.

검증: 기존 회귀 검증, 단계별 저장 실패 주입, 원본 보존과 캐시 무결성,
실제 Windows/Linux 프로세스 실행 및 배포판 실행 검증을 CI에서 수행합니다.
GPU 학습 속도나 생성 모델 성능 개선을 주장하는 릴리스가 아닙니다.
