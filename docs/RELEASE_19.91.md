# Deep Vision Studio 19.91

## 분할 라벨링

브러시 또는 지우개를 선택하면 도구 패널에서 1~1024px 범위의 크기를 슬라이더나 숫자로 바꿀 수 있습니다. `[`와 `]` 단축키도 사용할 수 있습니다. 커서 원은 원본 영상에서 적용되는 크기를 보여 줍니다. 획을 그리는 도중 바꾼 크기는 다음 획부터 적용됩니다.

## 객체 탐지 학습

- **LibreYOLO9 Tiny, D-FINE Nano, Re-DETR v4 Small·Medium·Large.** 학습 이미지에서 **패치 학습**을 켜고 이미지당 학습 패치 수를 지정한 뒤 **작은 물체가 포함된 패치 우선 선택**을 켭니다. 모델 입력에서 짧은 변이 16px 미만인 정답 박스가 온전히 들어간 패치를 우선합니다. 학습 로그에 기존 선택과 새 선택이 온전히 포함한 작은 박스 수가 표시됩니다.
- **Custom CSP.** 모델을 선택하고 **전경 보조 학습 (실험)**을 켭니다. 입력의 1/4 해상도 특징에 물체와 배경을 구분하는 학습 손실을 적용합니다. 보조 가중치는 에폭이 지날수록 줄어들고, 보조 헤드는 배포 모델에서 제외됩니다.

이 설정을 모델에 적용하려면 새 학습이나 기존 가중치로 추가 학습을 시작하세요. 탐지 패치 수와 작은 물체 우선 선택 설정은 같은 학습을 재개할 때 유지해야 합니다.

1920×640 합성 트레이에서 D-FINE Nano를 같은 패치 수로 두 번씩 학습했습니다. 보정과 분리한 시험 영상에서 IoU 0.5·점수 0.25 기준으로 작은 물체 검출은 61/74 → 63/74, 정답과 대응하지 않는 박스는 128 → 48이었습니다. 정상 영상의 불량 판정은 두 방식 모두 0/8이었습니다. 한 실행에서는 작은 물체 검출이 33/37 → 27/37로 줄어 옵션은 기본 해제입니다. Custom CSP는 별도 합성 데이터에서 두 번씩 학습하고 정상 검증 영상으로 모델별 임계값을 조정했습니다. 시험에서 작은 물체 검출은 65/86 → 57/86, 대응하지 않는 박스는 448 → 329였습니다. 분모는 같은 시험 데이터를 두 학습 결과에 적용한 합계입니다.

## ONNX 배포

객체 탐지는 **FP32**와 **INT8 QDQ**를 내보낼 수 있습니다. INT8은 보정용 정상·불량 이미지 폴더를 선택하세요. 앱은 FP32와 INT8의 검출 박스와 이미지별 판정을 비교하고, 판정이 바뀌거나 박스 차이가 기준을 넘으면 내보내기를 중단합니다. 결과에는 보정 영상에서의 누락·추가 박스 수가 기록됩니다.

위 D-FINE 실험에서 보정 검사를 통과한 INT8 모델은 별도 시험 영상에서 작은 물체 34/37을 검출했습니다. 같은 가중치의 FP32는 36/37을 검출했습니다. 두 번째 INT8 모델은 보정 영상에서 FP32 검출 27개 중 6개를 놓쳐 내보내기가 중단되었습니다.

## 출처

작은 물체에 학습 기회를 주는 접근과 전경 보조 손실은 공개 논문과 프리뷰를 바탕으로 Deep Vision Studio에서 직접 구현했습니다. 기존 모델과 가중치의 라이선스는 제3자 고지에 정리되어 있습니다. [YOLO26 논문](https://arxiv.org/html/2606.03748v1), [YOLO27 공식 프리뷰](https://docs.ultralytics.com/models/yolo27), [제3자 고지](../THIRD_PARTY_NOTICES.md).
