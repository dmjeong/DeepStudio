# 0.03: 레이어 관찰 지원 안내와 모델 선택 표시 수정

모델 선택 목록에서 내부 개발 단계인 sdk_verified/export_verified 표시를 제거했다. 이 값은 사용자의 체크포인트나 PC에서 수행한 검증 결과가 아니다.

레이어 관찰을 켜고 학습하면 관찰 탭을 먼저 열고, 초기 배치 기록 여부와 레이어 수를 로그에 표시한다. 관찰은 설정한 초기 1~10개 배치로 제한되며 이후 마지막 결과를 유지한다.

별도 학습 경로를 사용하는 ResNet, ConvNeXt, DeepLab V3+, U-Net은 관찰 기능이 연결되지 않았는데도 설정을 받을 수 있었다. 이제 해당 모델에서 관찰 설정을 비활성화하고 API에서도 명시적으로 거부한다. 지원 모델은 EfficientNet과 Custom CSP이며 PatchCore는 미지원이다.

실제 PyTorch 역전파 및 Qt 화면 검사 19개 통과. 사용자 Windows EXE에서 발생한 증상은 모델과 오류 정보 확인이 필요하다.
