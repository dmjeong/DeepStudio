# Deep Vision Studio 6.01

C++ 예제의 준비 추론을 벤치마크 반복문 앞에서 임의 호출하는 방식에서 `Classifier` 생성 시
자동 수행하는 방식으로 바꿨다. 프로그램 시작 시 객체를 생성하면 모델 로드, 전처리,
ONNX 실행, 후처리를 한 번 수행하고 성공한 뒤 반환한다. 추론 버튼은 이 시점 이후 활성화한다.

`Classifier(model_json, startup_image)`로 실제 카메라와 같은 형태의 입력을 전달할 수 있다.
이미지를 생략하면 모델 크기·채널 수에 맞춘 검은 이미지를 사용한다. 준비 추론 결과는 버리고,
오류는 생성자에서 전달한다. 버튼 클릭 시에는 기존 객체의 `Infer`만 호출한다.

`main.cpp`는 시작 비용과 준비 추론 시간, 준비 완료 후 첫 호출 시간을 따로 출력한다.
초기화 비용을 사용자 요청 전에 처리하지만 입력 변경이나 CPU 절전 등의 지연까지 보장하지는 않는다.
