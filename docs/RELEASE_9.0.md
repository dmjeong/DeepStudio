# Deep Vision Studio React 9.0

데이터셋의 기본 편집 기능과 클래스별 탐색을 추가하고 두 UI가 사용하는 학습/추론 계약을 정리했습니다.

- 클래스별 이미지 필터와 개수, 파일명 검색, 미라벨/오류 필터, 다중 선택
- 이미지 업로드와 로컬 폴더 가져오기, 이미지 및 정답의 분할 이동, 선택 이미지 클래스 변경
- 클래스 추가/이름 변경/백업 후 삭제, 이미지와 연결 정답의 백업 후 삭제
- 탐지 박스와 인스턴스 분할 폴리곤의 추가/삭제/클래스 수정
- 픽셀 마스크의 특정 클래스 일괄 변경 (자유 그리기 방식의 마스크 편집기는 포함하지 않음)
- Roboflow 데이터 관리 흐름을 참고한 클래스 탐색/이미지 작업 화면. Samsung Blue #1428A0 강조색
- 탭 이동/새로고침 시 프로젝트별 입력 초안 보존
- 프로젝트별 추론 이력, 가중치/입력 SHA256 기록, 원본과 결과 비교, 작은 미리보기 선계산
- 손상 작업 기록 보존 및 복구 가능한 앱 시작, 작업 ZIP 내보내기, 기간별 선택 정리와 임시 업로드 정리
- 상태 요약 API, 프로젝트 변경 시 상세 갱신, 여러 위젯의 동일 작업 폴링 공유
- 공식 사전학습 시작 / 내 가중치로 추가 학습 / 중단된 last.pt 재개 옵션 분리
- 완료되어 optimizer가 제거된 가중치의 잘못된 resume 요청 차단
- 저장소 기본 줄바꿈 설정 복원과 Windows BAT CRLF 규칙 유지

기존과 같이 릴리스 ZIP을 풀고 `start_web.bat`를 실행합니다. 필요한 pip 설치는 자동 처리합니다.

태그는 EXE와 구분하기 위해 `react-v9.0`을 사용합니다. Python/Qt 검증, 실제 ZIP의 Windows 실행과 브라우저 파일 편집 흐름이 통과해야 배포합니다.
