# Deep Vision Studio 20.01

**모델 내보내기 → 정밀도·CPU 스레드 비교**에서 FP32로 내보낸 모델의 배포 JSON과 시험 이미지 폴더를 선택합니다. ONNX 파일은 JSON이 가리키는 위치에 둡니다. 스레드 수는 `1, 2, 4, 8`처럼 입력합니다. `0`은 ONNX Runtime의 자동 설정입니다.

FP16과 INT8의 JSON을 이미 가지고 있다면 같은 가중치에서 생성한 파일을 선택합니다. 비워 두면 앱이 FP32 모델로부터 비교용 모델을 임시 생성합니다. INT8 자동 생성은 객체 탐지·분할·Dinomaly에서 지원하며 보정 이미지 폴더가 필요합니다. 이 비교 화면은 평문 ONNX와 배포 JSON을 받습니다.

워밍업 후 전체 시간과 모델 시간을 잽니다. 전체 시간에는 이미지 읽기, 전처리, 추론, 판정용 후처리가 포함됩니다. 모델 시간은 한 장을 처리하는 데 사용한 모든 ONNX 호출의 합입니다. p50은 중앙값이고 p95는 측정값의 95%가 그 이하였다는 뜻입니다. 출력 비교는 같은 스레드 수의 FP32를 기준으로 합니다. FP16 그래프는 CPU에서 일부 연산을 FP32로 처리할 수 있습니다. [ONNX Runtime FP16 문서](https://onnxruntime.ai/docs/performance/model-optimizations/float16.html).
