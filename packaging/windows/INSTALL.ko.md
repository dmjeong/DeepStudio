# Deep Vision Studio 설치본 사용 안내

`app/DeepVisionStudio.exe`를 실행하세요. `app` 안의 DLL·`_internal` 폴더를 지우거나 EXE만 따로 옮기면 실행할 수 없습니다. Python/pip/Node/Git은 사용 PC에 따로 설치하지 않아도 됩니다. 개발 예제는 옆의 `Examples/cpp`, `Examples/csharp`에 있습니다.

## 배포 기준 사양

- Windows 11 x64, Intel/AMD x64 CPU. ARM Windows용 패키지가 아닙니다.
- 메모리 16GB 이상을 기준으로 배포하며, 대형 이미지 학습·동시 작업은 32GB 이상을 권장합니다. 큰 모델/배치에는 더 필요할 수 있습니다.
- SSD 공간: 설치 프로그램이 요구하는 공간 외에 데이터셋·학습 결과·합성 후보 저장 공간을 확보하세요. 전체 가중치와 CUDA 포함 설치본은 용량이 크므로 50GB 이상 여유 공간을 권장합니다.
- CPU 추론에는 NVIDIA GPU가 필요 없습니다. GPU 학습은 CUDA PyTorch와 호환되는 NVIDIA GPU/드라이버가 필요합니다. VRAM 12GB 이상을 권장하되, 실제 필요한 용량은 모델·입력 크기·배치에 따라 다릅니다.

이 숫자는 모든 모델의 최대 해상도 실행이나 특정 추론 시간을 보장하는 값이 아닙니다. Windows CI에서 EXE·설치·CPU 추론을 확인하고, 실제 GPU 학습은 배포 대상 GPU/드라이버로 별도 확인해야 합니다.

## 기본 가중치

정식 오프라인 설치본은 빌드 시 모든 기본 사전학습 가중치 검사를 통과해야 합니다. ‘가중치 없음’이 나오면 설치본 제작자에게 `build.bat installer gpu`의 다운로드/검증 로그를 확인해 달라고 요청하세요. CI에서 설치 동작만 확인한 최소 자산 패키지는 정식 오프라인 배포물과 구분합니다.

## 프로젝트 클래스 생성

Data Gen → 프로젝트 클래스 생성 → 원하는 클래스 체크 → 생성 방식·장수·크기·강도 설정 → 후보 생성 → 원본/정답 확인 → 저장할 후보 체크 → 승인·새 프로젝트 저장.

프로젝트에 등록한 이름을 그대로 사용합니다. 이름만으로 실제 불량 형상을 자동 학습하지 않으므로 실제 결함과 맞는 후보만 승인하세요. SEG 정답 참조 생성과 학습형 Data Gen도 별도 탭에 있습니다. 이상검출 합성 불량은 정상 학습에 넣지 않고 별도 합성 평가 프로젝트로 만듭니다.

## 패치 학습

입력 크기는 모델이 한 번에 받는 이미지 크기입니다. SEG에서 입력 640 + 패치 100%는 원본을 640×640씩 잘라 학습합니다. 패치를 끄면 원본 전체를 640×640으로 축소합니다. 패치 배율 50%는 원본을 절반으로 줄인 뒤 잘라 작은 결함도 절반 크기가 됩니다.

## 저장 위치

프로젝트의 데이터셋·학습 결과·생성 후보는 프로젝트 폴더 안에 있습니다. 앱 실행 기록과 추론 결과 캐시는 사용자 폴더의 `.deep-vision-studio-desktop/jobs`에 있습니다. 작업 중에는 지우지 마세요. 기록 삭제는 추론 화면의 작업 기록에서 할 수 있으며, 삭제한 결과는 다시 추론해야 합니다.
